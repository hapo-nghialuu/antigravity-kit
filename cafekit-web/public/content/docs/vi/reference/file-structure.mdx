## Chi tiết File

### AI Config Files

| File | Claude | Antigravity | Mục đích |
|------|--------|-------------|----------|
| `CLAUDE.md` / `AGENTS.md` | ✅ | ✅ | Quick reference cho AI |
| `ROUTING.md` | ✅ | ❌ | Agent routing rules |
| `GEMINI.md` | ❌ | ✅ | Gemini-specific context |
| `ARCHITECTURE.md` | ❌ | ✅ | Framework architecture |
| `CONVENTIONS.md` | ❌ | ✅ | Platform conventions |

### Spec Files

| File | Mô tả | Tạo bởi |
|------|-------|---------|
| `spec.md` | Feature overview | `/spec-init` |
| `requirements.md` | EARS requirements | `/spec-requirements` |
| `design.md` | Technical design | `/spec-design` |
| `tasks.md` | Task breakdown | `/spec-tasks` |
| `implementation.md` | Progress tracking | `/spec-impl`, `/spec-status` |

### Documentation Files

| File | Mô tả | Cập nhật bởi |

| `code-standards.md` | Coding conventions | `/docs init`, `/docs update` |
| `system-architecture.md` | Architecture docs | `/docs init`, `/docs update` |
| `design-guidelines.md` | UI/UX guidelines | `/docs init`, `/docs update` |
| `deployment-guide.md` | Deployment guide | `/docs init`, `/docs update` |
| `project-roadmap.md` | Project roadmap | `/docs init`, `/docs update` |

## Quyền và Git

### Nên commit
- `CLAUDE.md` / `AGENTS.md`
- `specs/` (tất cả spec files)
- `docs/` (documentation)

### Không nên commit
- `.backups/` (tự động tạo, có thể lớn)
- `repomix-output.xml` (tạo lại được)

### Gitignore mẫu

```gitignore
# CafeKit Spec backups
docs/.backups/
repomix-output.xml
```

## Di chuyển giữa Platform

### Từ Claude Code sang Antigravity
```bash
# Backup specs và docs
cp -r specs specs-backup
cp -r docs docs-backup

# Cài đặt Antigravity
npx @haposoft/cafekit-spec
# Chọn Antigravity

# Restore specs và docs
cp -r specs-backup/* specs/
cp -r docs-backup/* docs/
```

### Từ Antigravity sang Claude Code
```bash
# Backup specs và docs
cp -r specs specs-backup
cp -r docs docs-backup

# Cài đặt Claude Code
npx @haposoft/cafekit-spec
# Chọn Claude Code

# Restore specs và docs
cp -r specs-backup/* specs/
cp -r docs-backup/* docs/
```

Specs và docs là **platform-agnostic**, chỉ cần chuyển là dùng được ngay.
