## Claude Code

Claude Code nhận full runtime:

- `.claude/skills`
- `.claude/agents`
- `.claude/hooks`
- `.claude/settings.json`
- `.claude/runtime.json`
- `.claude/status.cjs`
- root `CLAUDE.md`

## OpenCode

OpenCode nhận:

- `.opencode/commands`
- `.opencode/agents`
- `.opencode/cafekit.json`
- root `AGENTS.md`
- merged `opencode.json`
- shared `.claude/skills`, `.claude/rules`, `.claude/scripts`, `.claude/references`, `.claude/runtime.json`

OpenCode command cố ý bỏ `hapo:`.

## Future platforms

Cursor chưa phải runtime target trong installer hiện tại.
