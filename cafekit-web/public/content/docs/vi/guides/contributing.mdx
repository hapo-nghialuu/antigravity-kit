# Đóng góp cho CafeKit Spec

Cảm ơn bạn đã quan tâm đến việc đóng góp cho CafeKit Spec! Hướng dẫn này sẽ giúp bạn bắt đầu.

## Cách đóng góp

### 1. Báo cáo vấn đề (Issues)

Tìm thấy lỗi hoặc có đề xuất? Hãy mở một issue trên GitHub:

- **Báo cáo lỗi (Bug reports)**: Mô tả chuyện gì đã xảy ra, bạn mong đợi điều gì, và các bước để tái hiện
- **Yêu cầu tính năng (Feature requests)**: Giải thích trường hợp sử dụng (use case) và tại sao nó lại có giá trị
- **Vấn đề tài liệu**: Chỉ ra tài liệu không rõ ràng hoặc không chính xác

[Mở một Issue →](https://github.com/hapo-nghialuu/hapo-cafekit/issues)

### 2. Cải thiện tài liệu

Cải thiện tài liệu luôn được hoan nghênh:

- Sửa lỗi chính tả hoặc giải thích chưa rõ
- Thêm ví dụ vào các hướng dẫn hiện có
- Dịch tài liệu sang ngôn ngữ khác
- Tạo video hướng dẫn

### 3. Gửi thay đổi code (Code Changes)

Muốn sửa lỗi hoặc thêm tính năng? Làm theo các bước sau:

## Thiết lập môi trường phát triển

### Yêu cầu

- Node.js 18+
- Git
- Claude Code (để testing)

### Clone Repository

```bash
git clone https://github.com/hapo-nghialuu/hapo-cafekit.git
cd cafekit
```

### Cài đặt Dependencies

```bash
# Cài đặt root dependencies
npm install

# Cài đặt dependencies cho gói spec
cd packages/spec
npm install
```

### Cấu trúc dự án

```
cafekit/
├── packages/
│   └── spec/              # gói @haposoft/cafekit-spec
│       ├── bin/           # CLI installer
│       └── src/           # Source files
├── cafekit-web/           # Website tài liệu
│   └── content/docs/      # Tài liệu MDX
└── .claude/
    └── commands/          # Các lệnh quy trình spec
```

## Thực hiện thay đổi

### 1. Spec Commands

6 lệnh quy trình spec nằm trong `.claude/commands/`:

- `spec-init.md`
- `spec-requirements.md`
- `spec-design.md`
- `spec-tasks.md`
- `spec-impl.md`
- `spec-status.md`

Để sửa đổi một lệnh:

1. Chỉnh sửa file `.md`
2. Test lệnh trong Claude Code
3. Cập nhật tài liệu nếu cần

### 2. Gói Installer

Installer nằm trong `packages/spec/`:

```bash
cd packages/spec

# Test local
node bin/install.js

# Hoặc link để testing
npm link
npx @haposoft/cafekit-spec
```

### 3. Tài liệu

Tài liệu nằm trong `cafekit-web/content/docs/`:

```bash
cd cafekit-web

# Chạy dev server
npm run dev

# Chỉnh sửa file MDX
# Thay đổi sẽ tự động hot-reload
```

## Quy trình Pull Request

### 1. Tạo nhánh (Branch)

```bash
git checkout -b feature/your-feature-name
```

### 2. Thực hiện thay đổi của bạn

- Viết code rõ ràng, súc tích
- Tuân theo phong cách code hiện có
- Thêm/cập nhật tests nếu có thể áp dụng
- Cập nhật tài liệu

### 3. Test thay đổi của bạn

```bash
# Test installer
cd packages/spec
node bin/install.js

# Test các lệnh trong Claude Code
# (Copy file .md vào .claude/commands/ và test)
```

### 4. Commit thay đổi của bạn

```bash
git add .
git commit -m "feat: add feature description"
```

Sử dụng conventional commits:
- `feat:` - Tính năng mới
- `fix:` - Sửa lỗi
- `docs:` - Thay đổi tài liệu
- `refactor:` - Tái cấu trúc code (refactor)
- `test:` - Thay đổi test

### 5. Gửi Pull Request

1. Push lên fork của bạn
2. Mở PR vào nhánh `main`
3. Điền vào mẫu PR
4. Link bất kỳ issue nào liên quan

## Phong cách Code (Code Style)

### Markdown Files

- Sử dụng ngôn ngữ rõ ràng, súc tích
- Bao gồm ví dụ code ở nơi hữu ích
- Sử dụng frontmatter đúng

```yaml
---
title: Tiêu đề trang
description: Mô tả ngắn gọn
---
```

### JavaScript/TypeScript

- Sử dụng 2 dấu cách để thụt đầu dòng (indentation)
- Sử dụng dấu nháy đơn cho chuỗi (strings)
- Thêm JSDoc comments cho các hàm

## Testing

Trước khi gửi PR, hãy test các thay đổi của bạn:

1. **Test installer**
   ```bash
   cd packages/spec
   node bin/install.js
   ```

2. **Test spec commands**
   - Copy các lệnh đã sửa vào `.claude/commands/`
   - Chạy từng lệnh trong Claude Code
   - Xác minh hành vi mong đợi

3. **Test tài liệu**
   ```bash
   cd cafekit-web
   npm run build
   ```

## Quy trình Review

- Tất cả PR yêu cầu ít nhất một review
- Giải quyết phản hồi review kịp thời
- Giữ cho PR tập trung và nhỏ gọn

## Quy tắc ứng xử (Code of Conduct)

- Tôn trọng và hòa nhập
- Tập trung vào phản hồi mang tính xây dựng
- Giúp đỡ người khác học hỏi và phát triển
