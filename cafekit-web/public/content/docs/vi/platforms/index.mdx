# Hướng dẫn Nền tảng

CafeKit Spec hỗ trợ nhiều nền tảng trợ lý lập trình AI. Chọn nền tảng của bạn:

## Nền tảng được hỗ trợ

- **[Claude Code](/docs/platforms/claude)** - CLI Claude Code của Anthropic
- **[Antigravity](/docs/platforms/antigravity)** - IDE Antigravity của Google

Cả hai nền tảng đều hỗ trợ các lệnh spec workflow giống nhau, với một số khác biệt nhỏ về định dạng lệnh và tính năng.
