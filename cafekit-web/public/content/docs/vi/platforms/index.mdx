# Platforms

CafeKit is currently focused on a single runtime:

- [Claude Code](/vi/docs/platforms/claude) — available now

Planned runtimes:

- [Antigravity](/vi/docs/platforms/antigravity) — coming soon
- [Cursor](/vi/docs/platforms/cursor) — coming soon

## Recommendation

If you are starting a new project now, use Claude Code.
