# Claude Code

Hướng dẫn đầy đủ để sử dụng CafeKit Spec với Claude Code.

## Cài đặt

```bash
npx @haposoft/cafekit
```

Chọn **Claude Code** trong menu cài đặt.

## Cấu trúc file

Sau khi cài đặt, CafeKit Spec thêm các workflow vào `.claude/`:

```
.claude/
├── commands/
│   ├── spec-init.md
│   ├── spec-requirements.md
│   ├── spec-design.md
│   ├── spec-tasks.md
│   ├── spec-status.md
│   ├── code.md
│   ├── test.md
│   ├── review.md
│   └── docs.md
├── agents/
│   ├── tester.md
│   ├── code-reviewer.md
│   ├── fullstack-developer.md
│   └── debugger.md
├── skills/
│   └── specs/
└── ROUTING.md
```

## Bộ lệnh

### Quy trình spec
| Command | Mô tả |
|---------|-------|
| `/spec-init` | Khởi tạo spec mới |
| `/spec-requirements` | Thu thập và sinh requirements |
| `/spec-design` | Sinh thiết kế kỹ thuật |
| `/spec-tasks` | Sinh danh sách task triển khai |
| `/code` | Triển khai task đã duyệt tiếp theo |
| `/test` | Chạy test và tóm tắt lỗi |
| `/review` | Review correctness và security |
| `/spec-status` | Xem trạng thái hiện tại của spec |

### Quy trình documentation
| Command | Mô tả |
|---------|-------|
| `/docs init` | Khởi tạo docs dự án |
| `/docs update` | Cập nhật docs sau thay đổi |

## Ví dụ sử dụng

### Bắt đầu feature

```
> /spec-init payment-gateway
```

### Triển khai từ tasks

```
> /code payment-gateway
> /test
> /review
```

### Quản lý documentation

```
> /docs init
> /docs update
```

## Khác biệt so với Antigravity

| | Claude Code | Antigravity |
|---|---|---|
| Thư mục workflow | `.claude/commands/` | `.agent/workflows/` |
| Thư mục agent | `.claude/agents/` | `.agent/agents/` |
| File định tuyến | `.claude/ROUTING.md` | `.agent/rules/GEMINI.md` |
| Cách gọi lệnh | `/...` | `/...` hoặc `@...` |

## Khắc phục sự cố

### Không thấy command
```bash
ls -la .claude/commands/
```

### Lỗi chạy command
- Khởi động lại Claude Code
- Kiểm tra file command là `.md` và có frontmatter hợp lệ
- Chạy lại bộ cài đặt: `npx @haposoft/cafekit`
