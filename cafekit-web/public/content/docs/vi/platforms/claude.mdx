# Claude Code

Hướng dẫn đầy đủ cho việc sử dụng CafeKit Spec với Claude Code - AI assistant từ Anthropic.

## Cài đặt

```bash
npx @haposoft/cafekit-spec
```

Chọn **Claude Code** trong menu cài đặt.

## Cấu trúc File

Sau khi cài đặt, các file được tạo trong thư mục `.claude/`:

```
.claude/
├── CLAUDE.md                 # AI quick reference
├── ROUTING.md                # Agent routing rules
└── commands/
    ├── spec-init.ts          # /spec-init
    ├── spec-requirements.ts  # /spec-requirements
    ├── spec-design.ts        # /spec-design
    ├── spec-tasks.ts         # /spec-tasks
    ├── spec-impl.ts          # /spec-impl
    ├── spec-status.ts        # /spec-status
    ├── docs-init.ts          # /docs init
    └── docs-update.ts        # /docs update
```

## Command Syntax

Tất cả commands trong Claude Code sử dụng **dấu gạch ngang** (hyphens):

### Spec Workflows
| Command | Mô tả |
|---------|-------|
| `/spec-init` | Khởi tạo spec mới |
| `/spec-requirements` | Phân tích yêu cầu |
| `/spec-design` | Thiết kế kỹ thuật |
| `/spec-tasks` | Chia nhỏ task |
| `/spec-impl` | Triển khai code |
| `/spec-status` | Kiểm tra tiến độ |

### Documentation Workflows
| Command | Mô tả |
|---------|-------|
| `/docs init` | Khởi tạo documentation |
| `/docs update` | Cập nhật documentation |

## Files Đặc biệt

### CLAUDE.md
File reference nhanh cho AI:

```markdown
# Project Context

## Commands
- /spec-init - Initialize feature spec
- /spec-requirements - Create requirements
...

## Project Structure
...

## Conventions
...
```

### ROUTING.md
Định nghĩa rules cho agent routing:

```markdown
# Agent Routing

## spec-init
- Trigger: /spec-init
- Prompt: "Initialize feature spec..."

## spec-impl
- Trigger: /spec-impl
- Prompt: "Implement task from spec..."
```

## Ví dụ sử dụng

### Khởi tạo feature mới

```
> /spec-init

Feature name: payment-gateway
Description: Tích hợp cổng thanh toán Stripe
...
```

### Triển khai từng task

```
> /spec-impl

Implement task: 3
Feature: payment-gateway
...
```

### Cập nhật documentation

```
> /docs update

Cập nhật docs sau khi thêm Stripe integration
```

## Khác biệt với Antigravity

| | Claude Code | Antigravity |
|---|---|---|
| **Syntax** | Hyphens (`/spec-init`) | Underscores (`/spec-init`) |
| **Directory** | `.claude/` | `.agent/` |
| **Config file** | `CLAUDE.md` | `AGENTS.md` |
| **Extra file** | `ROUTING.md` | `GEMINI.md` |
| **Agent system** | Single Claude instance | Multiple specialized agents |

## Tips

1. **Dùng TAB completion**: Claude Code hỗ trợ autocomplete commands
2. **Kiểm tra status thường xuyên**: `/spec-status` để theo dõi tiến độ
3. **Commit thường xuyên**: Sau mỗi `/spec-impl` thành công
4. **Custom ROUTING.md**: Thêm rules riêng cho dự án

## Troubleshooting

### Commands không hiển thị
```bash
# Kiểm tra cài đặt
ls -la .claude/commands/
```

### CLAUDE.md không được đọc
- Đảm bảo file ở root: `./CLAUDE.md`
- Khởi động lại Claude Code

### Lỗi khi chạy command
- Kiểm tra quyền file
- Chạy lại installer: `npx @haposoft/cafekit-spec`
