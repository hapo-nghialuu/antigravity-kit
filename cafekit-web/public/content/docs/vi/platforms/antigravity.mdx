# Antigravity

Hướng dẫn đầy đủ để sử dụng CafeKit với Antigravity.

## Cài đặt

```bash
npx @haposoft/cafekit
```

Chọn **Antigravity** trong menu cài đặt.

## Cấu trúc file

Sau khi cài đặt, CafeKit thêm các workflow vào `.agent/`:

```
.agent/
├── workflows/
│   ├── spec-init.md
│   ├── spec-requirements.md
│   ├── spec-design.md
│   ├── spec-tasks.md
│   ├── spec-status.md
│   ├── code.md
│   ├── test.md
│   ├── review.md
│   ├── docs-init.md
│   └── docs-update.md
├── agents/
│   ├── frontend-specialist.md
│   ├── test-engineer.md
│   └── code-archaeologist.md
├── skills/
│   └── specs/
└── rules/
    └── GEMINI.md
```

## Bộ lệnh

Antigravity hỗ trợ cả cú pháp `/command` và `@command`.

### Quy trình spec
| Command | Mô tả |
|---------|-------|
| `/spec-init` | Khởi tạo spec mới |
| `/spec-requirements` | Thu thập và sinh requirements |
| `/spec-design` | Sinh thiết kế kỹ thuật |
| `/spec-tasks` | Sinh danh sách task triển khai |
| `/code` | Triển khai task đã duyệt tiếp theo |
| `/test` | Chạy test và tóm tắt lỗi |
| `/review` | Review correctness và security |
| `/spec-status` | Xem trạng thái hiện tại của spec |

### Quy trình documentation
| Command | Mô tả |
|---------|-------|
| `/docs-init` | Khởi tạo docs dự án |
| `/docs-update` | Cập nhật docs sau thay đổi |

## Ví dụ sử dụng

### Bắt đầu feature

```
> /spec-init payment-gateway
# hoặc
> @spec-init payment-gateway
```

### Triển khai từ tasks

```
> /code payment-gateway
> /test
> /review
```

### Cập nhật documentation

```
> /docs-update
```

## Khác biệt so với Claude Code

| | Antigravity | Claude Code |
|---|---|---|
| Thư mục workflow | `.agent/workflows/` | `.claude/commands/` |
| Thư mục agent | `.agent/agents/` | `.claude/agents/` |
| File định tuyến | `.agent/rules/GEMINI.md` | `.claude/ROUTING.md` |
| Cách gọi lệnh | `/...` hoặc `@...` | `/...` |

## Khắc phục sự cố

### Không thấy command
```bash
ls -la .agent/workflows/
```

### Lỗi chạy command
- Khởi động lại Antigravity
- Kiểm tra file workflow là `.md` và có frontmatter hợp lệ
- Chạy lại bộ cài đặt: `npx @haposoft/cafekit`
