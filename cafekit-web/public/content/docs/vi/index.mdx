# Tài liệu CafeKit

CafeKit là một **runtime bundle Claude Code-first** cho quy trình phát triển theo spec. Nó cài các workflow, agent, hook và runtime context để đi từ ý tưởng tới implementation đã được verify mà không phụ thuộc vào prompt rời rạc.

## Dành Cho Ai

Hãy dùng CafeKit nếu bạn muốn:

- một feature workflow có cấu trúc thay vì prompting từng lần
- spec artifacts đi cùng project
- task-level execution với verification rõ ràng
- review và docs checkpoint trước khi claim công việc đã xong

## Vòng Lặp Cốt Lõi

```text
Ý tưởng
  -> /hapo:specs
  -> /hapo:develop
  -> /hapo:test
  -> /hapo:code-review
```

Các command hỗ trợ thường dùng:

- `/hapo:specs --validate <feature>`
- `/hapo:sync audit <feature>`
- `/hapo:generate-graph <request>`
- `/docs init` và `/docs update` cho workflow tài liệu dự án

## CafeKit Cài Gì

Khi cài, CafeKit thêm runtime bundle vào `.claude/`:

```text
.claude/
├── skills/
├── agents/
├── hooks/
├── settings.json
├── runtime.json
├── status.cjs
└── CLAUDE.md
```

Release surface chính là:

- `/hapo:specs`
- `/hapo:develop`
- `/hapo:test`
- `/hapo:code-review`
- `/hapo:generate-graph`
