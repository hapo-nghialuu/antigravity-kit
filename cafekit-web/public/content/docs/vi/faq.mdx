## OpenCode đã supported chưa?

Có. Installer ghi runtime `.opencode/` self-contained với skills, agents, commands, rules, references, scripts, `runtime.json`, và TypeScript plugins trong `.opencode/plugins/`. Cũng ghi root `AGENTS.md` và merge `opencode.json`. OpenCode không chia sẻ file với `.claude/`.

## Task nào cũng cần `/hapo:specs`?

Không. Dùng specs cho feature work có ý nghĩa. Dùng `/hapo:debug` và `/hapo:fix` cho bugs. Fix nhỏ local có thể không cần full spec.

## Vì sao CafeKit cần task files?

Task files giữ scope, steps, completion criteria, và evidence. Chúng nối human intent với machine-checkable state.

## `NO_TESTS` có phải pass không?

Không. Nó chỉ nói rằng chưa có test suite thật nào chạy. Build health, runtime proof, và task evidence vẫn quan trọng.

## Có thể mark `done` từ chat không?

Không. `done` cần state sync vật lý trong `spec.json` và task markdown sau verify mới.

## Production bug thì dùng gì?

Bắt đầu bằng `/hapo:debug` khi chưa biết root cause. Dùng `/hapo:fix` sau diagnosis hoặc khi bug và target fix đã rõ.
