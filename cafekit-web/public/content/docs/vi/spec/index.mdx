## Syntactic Differences

| Platform | Syntax |
|----------|--------|
| **Claude Code** | `/spec-init`, `/spec-requirements`, `/spec-design`, `/spec-tasks`, `/code`, `/test`, `/review`, `/spec-status` |
| **Antigravity** | `/spec-init`, `/spec-requirements`, `/spec-design`, `/spec-tasks`, `/code`, `/test`, `/review`, `/spec-status` |

## Quy trình SDD

```text
/spec-init -> /spec-requirements -> /spec-design -> /spec-tasks -> /code -> /test -> /review
                                            |
                                            +--> /spec-status (xem phase hiện tại bất kỳ lúc nào)
```

## Khi nào dùng Spec Workflows?

### Dùng khi:
- Phát triển tính năng mới phức tạp
- Cần tài liệu kỹ thuật rõ ràng
- Làm việc nhóm, cần alignment
- Refactoring codebase lớn

### Không cần khi:
- Fix bug đơn giản
- Thay đổi nhỏ (1-2 dòng code)
- Hotfix production

## Files Được Tạo

Các file cốt lõi được tạo bởi các phase spec:

```
.specs/
└── [feature-name]/
    ├── spec.json            # Metadata phase + trạng thái phê duyệt
    ├── requirements.md      # Đầu vào/đầu ra requirements
    ├── research.md          # Ghi chú discovery (nếu cần)
    ├── design.md            # Technical design (từ spec-design)
    └── tasks.md             # Task breakdown (từ spec-tasks)
```
