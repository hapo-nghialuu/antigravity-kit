# /code

Triển khai công việc từ `.specs/[feature-name]/tasks.md` theo từng task.

## Sử dụng

**Claude Code:**
```bash
/code user-authentication
```

**Antigravity:**
```bash
/code user-authentication
# hoặc
@code user-authentication
```

## Mô tả

`/code` bắt đầu từ danh sách tasks đã tạo và thực thi task pending tiếp theo.

Luồng điển hình:
1. Đọc `.specs/[feature-name]/tasks.md`
2. Chọn task pending tiếp theo
3. Triển khai đúng phạm vi tối thiểu của task đó
4. Cập nhật trạng thái task trong file tasks
5. Bàn giao sang `/test` và `/review`

## Lưu ý

- Giữ implementation theo từng bước nhỏ, dễ review
- Tránh làm vượt phạm vi so với requirements/design đã duyệt
- Hoạt động tốt nhất sau khi `/spec-tasks` đã được duyệt

## Bước tiếp theo

- [`/test`](/docs/spec/test) - Kiểm tra implementation
- [`/review`](/docs/spec/review) - Review chất lượng và regression
- [`/spec-status`](/docs/spec/status) - Xem tiến độ tổng thể
