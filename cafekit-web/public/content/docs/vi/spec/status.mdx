# /spec-status

Kiểm tra và hiển thị trạng thái tổng quan của feature implementation.

## Sử dụng

**Claude Code:**
```
/spec-status
```

**Antigravity:**
```
/spec-status
```

## Mô tả

Lệnh này đọc tất cả các file trong spec directory và hiển thị báo cáo tiến độ:
- Spec completeness (đã có những gì)
- Task completion rate
- Files được tạo
- Next steps

## Cách đọc status

### Progress Bar
- 0-25%: Planning phase
- 25-50%: Core implementation
- 50-75%: Feature complete
- 75-100%: Polish & testing

### Task States
- ✅ Completed - Đã implement và test
- 🔄 In Progress - Đang làm
- ⏳ Pending - Chưa bắt đầu
- ⏸️ Blocked - Bị block (có dependency chưa xong)

## Sử dụng trong workflow

### Daily check-in
```

```
