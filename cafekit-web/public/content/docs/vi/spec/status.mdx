# /spec-status

Xem trạng thái của một spec hoặc liệt kê tất cả spec.

## Sử dụng

**Claude Code:**
```bash
/spec-status user-authentication
/spec-status
```

**Antigravity:**
```bash
/spec-status user-authentication
/spec-status
```

## Mô tả

`/spec-status` đọc metadata từ `.specs/*/spec.json` và tóm tắt:
- Phase hiện tại
- Trạng thái generated/approved của requirements, design, tasks
- Thời điểm cập nhật gần nhất
- Hành động tiếp theo được khuyến nghị

## Ví dụ một spec

```text
> /spec-status user-authentication

## 📊 Spec Status: user-authentication

| Property | Value |
|----------|-------|
| Phase | tasks-generated |
| Updated | 2026-02-24T10:20:00Z |

### Approvals
- Requirements: ✅ Generated | ✅ Approved
- Design: ✅ Generated | ✅ Approved
- Tasks: ✅ Generated | ❌ Approved

### Files
- spec.json ✅
- requirements.md ✅
- research.md ✅
- design.md ✅
- tasks.md ✅

### Next Action
Chạy `/code user-authentication`, sau đó `/test`, rồi `/review`.
```

## Ví dụ tất cả spec

```text
> /spec-status

| Feature | Phase | Last Updated |
|---------|-------|--------------|
| user-authentication | tasks-generated | 2026-02-24 |
| payment-gateway | requirements-generated | 2026-02-23 |
```

## Lưu ý

- Nguồn dữ liệu chính là `.specs/[feature-name]/spec.json`
- Trạng thái được cập nhật khi bạn đi qua `/spec-*`, `/code`, `/test`, `/review`
