# /spec-init

Khởi tạo một workspace spec mới trong `.specs/`.

## Sử dụng

**Claude Code:**
```bash
/spec-init "xác thực người dùng bằng email và mật khẩu"
```

**Antigravity:**
```bash
/spec-init "xác thực người dùng bằng email và mật khẩu"
# hoặc
@spec-init "xác thực người dùng bằng email và mật khẩu"
```

## Mô tả

`/spec-init` là bước đầu tiên của quy trình CafeKit Spec.

Lệnh này tạo thư mục mới tại `.specs/[feature-name]/` và khởi tạo:
- `spec.json` (metadata phase + trạng thái phê duyệt)
- `requirements.md` (nơi chứa mô tả đầu vào của dự án)

## Điều gì xảy ra

1. Sinh tên feature từ mô tả của bạn
2. Tạo `.specs/[feature-name]/`
3. Ghi file `spec.json` ban đầu
4. Ghi file `requirements.md` ban đầu với mô tả dự án

## Ví dụ output

```text
> /spec-init "xác thực người dùng bằng email và mật khẩu"

✅ Created: .specs/user-authentication/
✅ Created: .specs/user-authentication/spec.json
✅ Created: .specs/user-authentication/requirements.md
```

`requirements.md` ban đầu có dạng:

```markdown
# Requirements Document

## Project Description (Input)
Xác thực người dùng bằng email và mật khẩu

## Requirements
<!-- Will be generated in /spec-requirements phase -->
```

## Lưu ý

- Tên feature được sinh theo `kebab-case`
- Phase này chỉ khởi tạo cấu trúc và metadata
- Requirements/design/tasks được tạo ở các phase tiếp theo

## Bước tiếp theo

- [`/spec-requirements`](/docs/spec/requirements) - Sinh requirements chi tiết từ mô tả dự án
