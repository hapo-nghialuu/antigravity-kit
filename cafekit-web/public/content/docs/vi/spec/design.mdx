# /spec-design

Sinh tài liệu thiết kế kỹ thuật cho feature của bạn.

## Sử dụng

**Claude Code:**
```bash
/spec-design user-authentication
```

**Antigravity:**
```bash
/spec-design user-authentication
# hoặc
@spec-design user-authentication
```

## Mô tả

`/spec-design` đọc:
- `.specs/[feature-name]/spec.json`
- `.specs/[feature-name]/requirements.md`

Sau đó sinh:
- `.specs/[feature-name]/design.md`
- `.specs/[feature-name]/research.md` (khi cần discovery/research)

## Nội dung thiết kế bao gồm

- Kiến trúc và boundary
- Trách nhiệm component và interface
- Data model và contracts
- System flow (Mermaid khi cần)
- Chiến lược xử lý lỗi
- Chiến lược kiểm thử
- Yếu tố bảo mật và hiệu năng (khi áp dụng)

## Ví dụ output

```text
✅ Updated: .specs/user-authentication/design.md
✅ Updated: .specs/user-authentication/research.md
```

## Lưu ý

- Chuyển requirements (**what**) thành thiết kế triển khai (**how**)
- Nên review trước khi tạo task
- Lệnh cập nhật metadata phase trong `spec.json`
