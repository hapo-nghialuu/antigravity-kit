# /spec-design

Tạo tài liệu thiết kế kỹ thuật dựa trên requirements đã phân tích.

## Sử dụng

**Claude Code:**
```
/spec-design
```

**Antigravity:**
```
/spec_design
```

## Mô tả

Lệnh này đọc `spec.md` và `requirements.md` để tạo `design.md` - tài liệu mô tả chi tiết cách triển khai kỹ thuật.

## Nội dung Design Document

### 1. Technical Architecture

Mô tả kiến trúc tổng thể:
- Layer/component structure
- Data flow
- Integration points

### 2. Data Model

```
┌─────────────┐       ┌─────────────┐
│    User     │───────│   Session   │
├─────────────┤       ├─────────────┤
│ id          │       │ id          │
│ email       │       │ user_id     │
│ password    │       │ token       │
│ created_at  │       │ expires_at  │
└─────────────┘       └─────────────┘
```

### 3. API Design

| Method | Endpoint | Description | Request | Response |
|--------|----------|-------------|---------|----------|
| POST | /api/auth/login | Đăng nhập | `{email, password}` | `{token}` |
| POST | /api/auth/logout | Đăng xuất | `{token}` | `{success}` |

### 4. Error Handling

| Error Code | HTTP Status | Description |
|------------|-------------|-------------|
| AUTH001 | 401 | Invalid credentials |
| AUTH002 | 403 | Account locked |

### 5. Security Considerations

- JWT secret rotation
- Rate limiting
- Password hashing (bcrypt)
