# /spec-tasks

Sinh các task sẵn sàng triển khai từ bản thiết kế đã duyệt.

## Sử dụng

**Claude Code:**
```bash
/spec-tasks user-authentication
/spec-tasks user-authentication -y
```

**Antigravity:**
```bash
/spec-tasks user-authentication
/spec-tasks user-authentication -y
# hoặc
@spec-tasks user-authentication
```

## Mô tả

`/spec-tasks` đọc:
- `.specs/[feature-name]/spec.json`
- `.specs/[feature-name]/requirements.md`
- `.specs/[feature-name]/design.md`

Sau đó ghi:
- `.specs/[feature-name]/tasks.md`

Danh sách task sẽ được sắp thứ tự, ánh xạ requirements và sẵn sàng cho `/code`.

## Định dạng task

Định dạng phổ biến trong `tasks.md`:

```markdown
- [ ] 1. Thiết lập mô-đun xác thực
- [ ] 1.1 Tạo auth service interface
  - Định nghĩa method login/logout/session
  - _Requirements: 1, 2_

- [ ] 2. Thêm login endpoint
- [ ] 2.1 Triển khai POST /api/auth/login
  - Validate input và trả token/session
  - _Requirements: 1, 3_
```

## Lưu ý

- Task nên nhỏ, rõ ràng và theo thứ tự hợp lý
- Mỗi requirement cần được cover bởi ít nhất một task
- `-y` có thể auto-approve các điều kiện tiên quyết trước khi sinh task

## Bước tiếp theo

- [`/code`](/docs/spec/code) - Triển khai task pending tiếp theo
- [`/test`](/docs/spec/test) - Kiểm tra implementation
- [`/review`](/docs/spec/review) - Review chất lượng và regression
