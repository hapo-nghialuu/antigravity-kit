# /code

Triển khai code cho task pending tiếp theo trong `.specs/[feature-name]/tasks.md`.

## Sử dụng

**Claude Code:**
```bash
/code user-authentication
```

**Antigravity:**
```bash
/code user-authentication
```

## Mô tả

`/code` là giai đoạn triển khai sau `/spec-tasks`. Lệnh này tập trung xử lý từng task một để thay đổi nhỏ gọn, dễ test và dễ review.

## Quy trình

1. Đọc `.specs/[feature-name]/tasks.md`
2. Xác định task pending tiếp theo
3. Triển khai đúng task đó
4. Chạy `/test [feature-name]`
5. Chạy `/review [feature-name]`


## Kết quả

Kết quả thường thấy sau `/code`:
- Hoàn tất code cho task hiện tại
- Chạy kiểm thử qua `/test`
- Kiểm tra chất lượng/bảo mật qua `/review`

## Mẹo

- Mỗi lần chỉ triển khai một task để diff sạch
- Giữ thứ tự task trong `tasks.md`
- Luôn đi kèm `/code` với `/test` và `/review`

## Bước tiếp theo

- [`/test`](/docs/spec/test) - Kiểm tra implementation
- [`/review`](/docs/spec/review) - Review chất lượng và regression
- [`/spec-status`](/docs/spec/status) - Xem tiến độ tổng quan
