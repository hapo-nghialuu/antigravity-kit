# /docs update

Làm mới tài liệu dự án sau các thay đổi code quan trọng.

## Sử dụng

**Claude Code:**
```bash
/docs update
```

**Antigravity:**
```bash
/docs-update
```

## Mô tả

`/docs update` phân tích lại codebase hiện tại và cập nhật các phần docs đã thay đổi.

Luồng thường gặp:
1. Xác minh `docs/` tồn tại
2. Tạo backup/snapshot
3. Quét lại ngữ cảnh codebase (bao gồm repomix output)
4. Cập nhật file docs để khớp implementation hiện tại

## Các file thường được cập nhật

- `docs/codebase-summary.md`
- `docs/project-overview-pdr.md`
- `docs/code-standards.md`
- `docs/system-architecture.md`
- `docs/design-guidelines.md`
- `docs/deployment-guide.md`
- `docs/project-roadmap.md`
- File ngữ cảnh nền tảng (`CLAUDE.md` hoặc `.agent/rules/AGENTS.md`)

## Best practices

- Commit code trước khi chạy update
- Review diff docs sau khi update
- Chạy lại khi có thay đổi lớn về kiến trúc hoặc deployment
