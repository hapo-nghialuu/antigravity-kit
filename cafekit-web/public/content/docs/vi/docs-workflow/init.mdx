# /docs init

Tạo bộ documentation nền cho ngữ cảnh AI và team.

## Sử dụng

**Claude Code:**
```bash
/docs init
```

**Antigravity:**
```bash
/docs-init
```

## Mô tả

Lệnh này phân tích codebase và tạo các tài liệu cốt lõi.

Các output thường bao gồm:
- `docs/codebase-summary.md`
- `docs/project-overview-pdr.md`
- `docs/code-standards.md`
- `docs/system-architecture.md`
- `docs/design-guidelines.md`
- `docs/deployment-guide.md`
- `docs/project-roadmap.md`
- `repomix-output.xml`

File ngữ cảnh theo nền tảng:
- **Claude**: `CLAUDE.md`
- **Antigravity**: `.agent/rules/AGENTS.md`

## Lưu ý

- Nên chạy khi bắt đầu dự án hoặc khi docs còn thiếu
- Docs hiện có có thể được merge hoặc refresh tùy hành vi workflow
- Nên review và chỉnh lại các phần đặc thù của dự án

## Bước tiếp theo

- Chạy [`/docs update`](/docs/docs-workflow/update) sau các thay đổi code lớn
