## Tại sao cần Documentation Workflows?

### Vấn đề
Khi làm việc với AI assistant, mỗi lần bắt đầu session mới:
- AI không nhớ gì về dự án
- Phải mất thờì gian để AI đọc và hiểu codebase
- Context window bị hao tốn cho việc "catch up"

### Giải pháp
CafeKit Spec tạo 7 file documentation chuẩn hóa:
1. **codebase-summary.md** - Tổng quan codebase
2. **project-overview-pdr.md** - Yêu cầu sản phẩm
3. **code-standards.md** - Quy ước coding
4. **system-architecture.md** - Kiến trúc hệ thống
5. **design-guidelines.md** - Nguyên tắc UI/UX
6. **deployment-guide.md** - Hướng dẫn triển khai
7. **project-roadmap.md** - Lộ trình dự án

Plus **AGENTS.md** (Antigravity) hoặc **CLAUDE.md** (Claude Code) - File reference nhanh cho AI.

## Quy trình sử dụng

### Lần đầu setup dự án
```
> /docs init

Tạo tất cả documentation files
```

### Sau khi code thay đổi lớn
```
> /docs update

Cập nhật documentation để phản ánh code mới
```

## Best Practices

### Thờì điểm chạy `/docs init`
- Setup dự án mới
- Onboard AI assistant lần đầu
- Sau khi refactor cấu trúc lớn

### Thờì điểm chạy `/docs update`
- Sau khi thêm tính năng mới
- Sau khi thay đổi architecture
- Trước khi handover cho AI khác

## Chi tiết từng file

| File | Mục đích | Khi nào cập nhật |
|------|----------|------------------|
| codebase-summary.md | Tổng quan tech stack, structure | Thay đổi framework/library |
| project-overview-pdr.md | Requirements, goals | Thay đổi requirements |
| code-standards.md | Coding conventions | Thay đổi conventions |
| system-architecture.md | Architecture diagrams | Refactor architecture |
| design-guidelines.md | UI/UX standards | Thay đổi design system |
| deployment-guide.md | Deploy process | Thay đổi infrastructure |
| project-roadmap.md | Timeline, milestones | Planning mới |
