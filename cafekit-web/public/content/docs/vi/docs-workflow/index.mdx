# Documentation Workflows

Documentation Workflows cung cấp các lệnh để tự động hóa tài liệu dự án, giúp AI assistant hiểu codebase nhanh hơn.

## Ánh xạ lệnh theo nền tảng

| Platform | Cú pháp lệnh |
|----------|--------------|
| **Claude Code** | `/docs init`, `/docs update` |
| **Antigravity** | `/docs-init`, `/docs-update` |

## Vì sao cần Documentation Workflows?

### Vấn đề
Khi làm việc với AI assistant, mỗi session mới thường thiếu ngữ cảnh:
- AI phải đọc lại cấu trúc dự án
- Mất thời gian giải thích lại kiến trúc và quy ước
- Context window bị tiêu tốn cho việc catch-up

### Giải pháp
CafeKit chuẩn hóa việc tạo docs cho ngữ cảnh cốt lõi của dự án:
1. **codebase-summary.md** - Tổng quan codebase
2. **project-overview-pdr.md** - Yêu cầu sản phẩm
3. **code-standards.md** - Quy ước coding
4. **system-architecture.md** - Kiến trúc hệ thống
5. **design-guidelines.md** - Nguyên tắc UI/UX
6. **deployment-guide.md** - Hướng dẫn triển khai
7. **project-roadmap.md** - Lộ trình dự án

Kèm theo:
- **repomix-output.xml** để AI đọc ngữ cảnh codebase dạng nén
- **CLAUDE.md** (root, cho dự án Claude)
- **.agent/rules/AGENTS.md** (cho dự án Antigravity)

## File được tạo

## Cách dùng phổ biến

### Thiết lập lần đầu
```bash
/docs init
# Antigravity: /docs-init
```

### Sau thay đổi lớn
```bash
/docs update
# Antigravity: /docs-update
```

## Best practices

### Chạy init khi:
- Onboarding dự án mới
- Lần đầu chuẩn bị AI context
- Chưa có baseline documentation

### Chạy update khi:
- Merge tính năng lớn
- Có thay đổi kiến trúc/deployment
- Trước khi handoff cho người khác hoặc session AI khác
