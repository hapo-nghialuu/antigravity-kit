# Cài đặt

Cài CafeKit tại root của project:

```bash
npx @haposoft/cafekit
```

## Điều kiện cần

- Node.js 18+
- một project Claude Code
- project root có thể ghi để quản lý `.claude/`

Tuỳ chọn:

- `repomix` nếu bạn định dùng `/docs init` hoặc `/docs update`

```bash
npm install -g repomix
```

## Installer Làm Gì

CafeKit cài và quản lý một Claude runtime bundle:

```text
.claude/
├── skills/
├── agents/
├── hooks/
├── settings.json
├── runtime.json
├── status.cjs
└── CLAUDE.md
```

Nó cũng cài command surface chính:

- `/hapo:specs`
- `/hapo:develop`
- `/hapo:test`
- `/hapo:code-review`
- `/hapo:generate-graph`

## Kiểm tra cài đặt

Mở Claude Code trong project rồi chạy:

```bash
/hapo:specs Build a small feature from a clear problem statement
```

Nếu CafeKit đã được cài đúng, Claude sẽ vào spec workflow thay vì coi command này như plain text.

## Nâng cấp bản cài hiện có

Để refresh managed bundle:

```bash
npx @haposoft/cafekit --upgrade
```

## Ghi chú

- CafeKit là **Claude Code-first**.
- Antigravity và Cursor đang trong kế hoạch nhưng chưa có.
- `/docs init` và `/docs update` là workflow hỗ trợ, không phải phần bắt buộc của core install path.
