# /docs init

Initialize all project documentation so AI assistants can understand and work effectively.

## Usage

**Claude Code:**
```
/docs init
```

**Antigravity:**
```
/docs-init
```

## Description

This command scans the entire codebase and creates 7 standardized documentation files, along with an AI reference file.

## Output

### Documentation Files

```
docs/
├── codebase-summary.md      # Codebase overview
├── project-overview-pdr.md  # Product requirements
├── code-standards.md        # Coding conventions
├── system-architecture.md   # Architecture docs
├── design-guidelines.md     # UI/UX guidelines
├── deployment-guide.md      # Deployment guide
└── project-roadmap.md       # Project roadmap
```

### AI Context Files

```
# For Antigravity:
.agent/
├── AGENTS.md                # Quick reference for AI
├── rules/
│   └── 001-project.md       # Project context
└── ...

# For Claude Code:
.claude/
├── CLAUDE.md                # Quick reference for AI
├── commands/
└── ...
```

### repomix-output.xml

AI context file created at root:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<repository
  name="project-name"
  description="Auto-generated from codebase"
>
  <directory structure="...">
    ...
  </directory>
  <files>
    ...
  </files>
</repository>
```

## File Contents

### codebase-summary.md
- Tech stack (frameworks, libraries)
- Project structure
- Key directories
- Dependencies

### project-overview-pdr.md
- Product goals
- User personas
- Core features
- Success metrics

### code-standards.md
- Naming conventions
- File organization
- Code style
- Testing standards

### system-architecture.md
- System overview
- Data flow
- Component diagram
- External integrations

### design-guidelines.md
- Design system
- Component library
- Color palette
- Typography

### deployment-guide.md
- Environment setup
- Build process
- Deployment steps
- Monitoring

### project-roadmap.md
- Current phase
- Milestones
- Timeline
- Dependencies

## Process

```
1. Scan codebase
   └── AI reads all important files

2. Analyze structure
   └── Analyze architecture, patterns

3. Generate docs
   └── Create 7 markdown files

4. Create AI reference
   └── AGENTS.md or CLAUDE.md

5. Export repomix
   └── repomix-output.xml for AI context
```

## Execution Time

- **Small project** (< 100 files): ~1-2 minutes
- **Medium project** (100-1000 files): ~3-5 minutes
- **Large project** (> 1000 files): ~5-10 minutes

## Notes

- `/docs init` will **overwrite** existing files
- Backup is created automatically before overwriting
- Should review and edit docs after creation

## Next Steps

- Review files in `docs/`
- Edit to add specific information
- Run [`/docs update`](/docs/docs-workflow/update) when code changes
