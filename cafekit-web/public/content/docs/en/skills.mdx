## Catalog

| Skill | Use it for |
|---|---|
| `hapo:brainstorm` | Scout-first ideation before a spec is ready. |
| `hapo:specs` | Requirements, research, design, task generation, validation. |
| `hapo:develop` | Implement approved spec tasks. |
| `hapo:test` | Unit, integration, build, UI, and task-aware verification. |
| `hapo:code-review` | Adversarial review for regressions, security, and contract drift. |
| `hapo:sync` | Repair and audit `spec.json` plus task markdown state. |
| `hapo:debug` | Evidence-first root-cause diagnosis. |
| `hapo:hotfix` | Small safe fixes after diagnosis. |
| `hapo:inspect` | Codebase discovery and scoped file scouting. |
| `impact-analysis` | Blast-radius and regression scenario analysis. |
| `hapo:research` | External technical research and source validation. |
| `hapo:docs` | Project docs, summaries, updates, and as-is reconstruction. |
| `hapo:generate-graph` | Technical diagrams exported as SVG/PNG. |
| `hapo:git` | Safe branch, commit, push, and worktree operations. |
| `hapo:frontend-design` | Polished frontend redesign and visual execution. |
| `hapo:frontend-development` | React/TypeScript frontend implementation patterns. |
| `hapo:react-best-practices` | React and Next.js performance guidance. |
| `hapo:ui-ux-pro-max` | UI/UX rules, accessibility, layout, motion, and design intelligence. |
| `hapo:web-testing` | Playwright, Vitest, k6, visual, a11y, and performance testing. |
| `hapo:agent-browser` | Context-efficient browser automation snapshots. |
| `hapo:chrome-devtools` | Puppeteer browser automation, screenshots, console, and ARIA checks. |

| `hapo:pdf` | PDF extraction, creation, forms, merge, split, and batch work. |

| `hapo:xlsx` | Spreadsheet creation, formulas, charts, analysis, and recalculation. |

## Routing rule

Choose the smallest skill that fits the task. Do not force a full spec workflow for tiny fixes, and do not start coding when the request is still ambiguous.
