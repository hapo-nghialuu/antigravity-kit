# Platform Guides

CafeKit supports multiple AI coding assistant platforms. Choose your platform:

## Supported Platforms

- **[Claude Code](/docs/platforms/claude)** - Anthropic's Claude Code CLI
- **[Antigravity](/docs/platforms/antigravity)** - Google's Antigravity IDE

Both platforms support the same spec workflow commands, with minor differences in command format and availability.
