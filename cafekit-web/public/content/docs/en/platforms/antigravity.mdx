# Antigravity

Complete guide for using CafeKit Spec with Antigravity - AI assistant framework from Google.

## Installation

```bash
npx @haposoft/cafekit-spec
```

Select **Antigravity** in the installation menu.

## File Structure

After installation, files are created in the `.agent/` directory:

```
.agent/
├── AGENTS.md                 # AI quick reference
├── GEMINI.md                 # Gemini-specific context
├── ARCHITECTURE.md           # Architecture docs
├── CONVENTIONS.md            # Platform conventions
├── agents/
│   ├── spec-init.json        # spec-init agent
│   ├── spec-requirements.json
│   ├── spec-design.json
│   ├── spec-tasks.json
│   ├── spec-impl.json
│   ├── spec-status.json
│   ├── docs-init.json
│   └── docs-update.json
├── skills/
│   └── ...                   # 40+ reusable skills
└── workflows/
    ├── spec_init.yaml
    ├── spec_requirements.yaml
    ├── spec_design.yaml
    ├── spec_tasks.yaml
    ├── spec_impl.yaml
    ├── spec_status.yaml
    ├── docs-init.yaml
    └── docs-update.yaml
```

## Command Syntax

All commands in Antigravity use **underscores**:

### Spec Workflows
| Command | Description |
|---------|-------------|
| `/spec_init` | Initialize new spec |
| `/spec_requirements` | Analyze requirements |
| `/spec_design` | Technical design |
| `/spec_tasks` | Break down tasks |
| `/spec_impl` | Implement code |
| `/spec_status` | Check progress |

### Documentation Workflows
| Command | Description |
|---------|-------------|
| `/docs-init` | Initialize documentation |
| `/docs-update` | Update documentation |

## Special Files

### AGENTS.md
Quick reference file for AI:

```markdown
# Project Context

## Agents
- spec_init - Initialize feature spec
- spec_impl - Implement tasks
...

## Skills
- file_read, file_write, file_edit
- task_create, task_update
...
```

### GEMINI.md
Special context for Gemini model:

```markdown
# Gemini Configuration

## Model Settings
- Temperature: 0.2
- Max tokens: 8000

## Context Window
- Priority: AGENTS.md > GEMINI.md > codebase
```

### ARCHITECTURE.md
Framework architecture description:

```markdown
# Antigravity Architecture

## Agent System
- Specialized agents per workflow
- Skills-based composition

## Workflow Engine
- YAML-defined workflows
- State management
```

## Differences from Claude Code

| | Antigravity | Claude Code |
|---|---|---|
| **Syntax** | Underscores (`/spec_init`) | Hyphens (`/spec-init`) |
| **Directory** | `.agent/` | `.claude/` |
| **Config file** | `AGENTS.md` | `CLAUDE.md` |
| **Extra files** | `GEMINI.md`, `ARCHITECTURE.md` | `ROUTING.md` |
| **Agent system** | Multiple specialized agents | Single Claude instance |
| **Skills** | 40+ reusable skills | Built-in capabilities |

## Multi-Agent System

Antigravity uses multiple specialized agents:

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  spec_init  │────▶│ spec_design │────▶│  spec_impl  │
│    agent    │     │    agent    │     │    agent    │
└─────────────┘     └─────────────┘     └─────────────┘
      │                                       │
      ▼                                       ▼
┌─────────────┐                         ┌─────────────┐
│  Codebase   │◀────────────────────────│   skills    │
│   Context   │                         │  (40+ tools)│
└─────────────┘                         └─────────────┘
```

Each agent has:
- Its own prompt template
- Appropriate skill set
- Optimized context window

## Tips

1. **Use skills**: Antigravity has 40+ reusable skills
2. **Agent routing**: System automatically selects appropriate agent
3. **GEMINI.md**: Customize for Gemini model
4. **Workflow YAML**: Can edit workflows directly

## Troubleshooting

### Commands not showing
```bash
# Check installation
ls -la .agent/workflows/
```

### AGENTS.md not being read
- Ensure file is at root: `./AGENTS.md`
- Check Antigravity configuration

### Error running command
- Check agent definitions
- Re-run installer: `npx @haposoft/cafekit-spec`
