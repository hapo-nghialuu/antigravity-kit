# Antigravity (Coming Soon)

Antigravity is **not available yet** in the active CafeKit release line.

## Current Status

- Claude Code is the only actively documented and supported runtime
- Antigravity support is planned
- this page exists only to set expectations clearly

## Recommendation

If you need CafeKit today, use [Claude Code](/docs/platforms/claude).
