## Claude Code

Claude Code receives the full runtime:

- `.claude/skills`
- `.claude/agents`
- `.claude/hooks`
- `.claude/settings.json`
- `.claude/runtime.json`
- `.claude/status.cjs`
- root `CLAUDE.md`

## OpenCode

OpenCode receives:

- `.opencode/commands`
- `.opencode/agents`
- `.opencode/cafekit.json`
- root `AGENTS.md`
- merged `opencode.json`
- shared `.claude/skills`, `.claude/rules`, `.claude/scripts`, `.claude/references`, and `.claude/runtime.json`

OpenCode commands intentionally omit `hapo:`.

## Future platforms

Cursor is not packaged as a runtime target in the current installer.
