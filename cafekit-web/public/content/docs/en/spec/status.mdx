# /spec-status

Check and display the overall status of feature implementation.

## Usage

**Claude Code:**
```
/spec-status
```

**Antigravity:**
```
/spec_status
```

## Description

This command reads all files in the spec directory and displays a progress report:
- Spec completeness (what's available)
- Task completion rate
- Files created
- Next steps

## Reading Status

### Progress Bar
- 0-25%: Planning phase
- 25-50%: Core implementation
- 50-75%: Feature complete
- 75-100%: Polish & testing

### Task States
- ✅ Completed - Implemented and tested
- 🔄 In Progress - Currently working
- ⏳ Pending - Not started
- ⏸️ Blocked - Blocked (dependency not complete)

## Usage in Workflow

### Daily check-in
```
> /spec-status

Check end-of-day progress to know what to do tomorrow
```

### Pre-demo check
```
> /spec-status

Check what's done before demo
```

### Handover
```
> /spec-status

Create report for handover to someone else
```

## Notes

- Status is stored in `implementation.md`
- Updated automatically when running `/spec-impl`
- Can be manually edited if needed
