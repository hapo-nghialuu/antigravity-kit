# /code

Implement code for the next pending task in `.specs/[feature-name]/tasks.md`.

## Usage

**Claude Code:**
```bash
/code user-authentication
```

**Antigravity:**
```bash
/code user-authentication
```

## Description

`/code` is the implementation phase after `/spec-tasks`. It focuses on one pending task at a time to keep changes small, testable, and reviewable.

## Process

1. Read `.specs/[feature-name]/tasks.md`
2. Identify the next pending task
3. Implement only that task in code
4. Run `/test [feature-name]`
5. Run `/review [feature-name]`


## Output

Typical outcomes after `/code`:
- Task code changes completed
- Related tests executed via `/test`
- Quality/security checks performed via `/review`

## Tips

- Implement one task per run for clean diffs
- Keep task order from `tasks.md`
- Always pair `/code` with `/test` and `/review`
