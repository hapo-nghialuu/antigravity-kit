# /spec-status

特定の機能（spec）の進捗状況を確認するか、全体の一覧を表示します。

## 使い方

**Claude Code:**
```bash
/spec-status user-authentication
/spec-status
```

**Antigravity:**
```bash
/spec-status user-authentication
/spec-status
```

## 説明

`/spec-status` コマンドは `.specs/*/spec.json` のメタデータを読み込み、以下の情報をサマリー表示します：
- 現在の開発フェーズ（要件定義中、実装中など）
- 要件定義・設計・タスクの生成状況と、それぞれの承認ステータス
- 最終更新日時
- 次に実行すべきおすすめのアクション

## 単一Specのステータス表示例

```text
> /spec-status user-authentication

## 📊 Spec Status: user-authentication

| Property | Value |
|----------|-------|
| Phase | tasks-generated |
| Updated | 2026-02-24T10:20:00Z |

### Approvals
- Requirements: ✅ Generated | ✅ Approved
- Design: ✅ Generated | ✅ Approved
- Tasks: ✅ Generated | ❌ Approved

### Files
- spec.json ✅
- requirements.md ✅
- research.md ✅
- design.md ✅
- tasks.md ✅

### Next Action
Run `/code user-authentication`, then `/test`, then `/review`.
```

## 全Specの一覧表示例

```text
> /spec-status

| Feature | Phase | Last Updated |
|---------|-------|--------------|
| user-authentication | tasks-generated | 2026-02-24 |
| payment-gateway | requirements-generated | 2026-02-23 |
```

## メモ

- 進捗管理における「信頼できる唯一の情報源（Single Source of Truth）」は `.specs/[feature-name]/spec.json` ファイルです
- 開発が進み `/spec-*` 、 `/code` 、 `/test` 、 `/review` などのコマンドを実行していくと、このステータス情報も自動的に更新されていきます
