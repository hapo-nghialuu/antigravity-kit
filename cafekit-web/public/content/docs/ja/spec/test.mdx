# /test

直近の実装内容が正しく動くか、テストを実行して検証します。

## 使い方

**Claude Code:**
```bash
/test
/test user-authentication
```

**Antigravity:**
```bash
/test
/test user-authentication
# または
@test
```

## 説明

`/test` コマンドはプロジェクト内のテストを実行し、以下のような簡潔なレポートを出力します：
- テストの合否（Pass/Fail）サマリー
- 失敗した場合はそのテスト名
- エラーの根本原因として考えられる最も可能性の高い理由
- 問題解決に向けた次のアクション（修正案）の提示

## メモ

- 毎回の `/code` 実行直後に、セットで実行してください
- AIからのフィードバック（エラー原因など）は、具体的でアクション可能な内容に絞られます
- `/review` へ進む前に、すべてのテストがパスするまで修正と `/test` の再実行を繰り返してください

## 次のステップ

- テストが失敗した場合：コードを修正し、再度 `/test` を実行します
- テストが成功した場合：次のステップである [`/review`](/docs/spec/review) を実行します
