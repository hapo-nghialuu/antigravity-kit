# /review

タスクを完了とする前に、直近の実装コードの品質をレビュー（検証）します。

## 使い方

**Claude Code:**
```bash
/review
/review user-authentication
```

**Antigravity:**
```bash
/review
/review user-authentication
# または
@review
```

## 説明

`/review` コマンドは、以下の観点に重点を置いて直近のコード変更を検査します：
- コードの正当性（仕様通りに動くか）
- 潜在的なセキュリティリスク
- リグレッション（既存機能への破壊的な影響）のリスク
- コードの保守性（読みやすさ、構造の綺麗さなど）

AIからの指摘事項は、具体的な改善案とともに「重要度（Severity）」順にリストアップされます。

## メモ

- 必ず `/test` がすべてパスした後に実行してください
- レビュー範囲は、直近で変更されたコードのスコープ（範囲内）に限定されます
- 対象のタスクを完了扱いにする前に、重要度（High等）の高い指摘事項は必ず修正してください

## 次のステップ

- （指摘があった場合）指摘内容に沿ってコードを修正します
- 修正を行った場合は、念のため再度 `/test` と `/review` を実行します
- 問題がなくなったら [`/spec-status`](/docs/spec/status) を実行し、全体の進捗が正しく進んでいるか確認します
