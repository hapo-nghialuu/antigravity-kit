# /code

`.specs/[feature-name]/tasks.md` に記載されたタスクを、上から順に1つずつ実装していくコマンドです。

## 使い方

**Claude Code:**
```bash
/code user-authentication
```

**Antigravity:**
```bash
/code user-authentication
# または
@code user-authentication
```

## 説明

`/code` を実行すると、AIが未完了のタスクを自動的に見つけ出し、実装作業を開始します。

実行時の一般的なフロー：
1. `.specs/[feature-name]/tasks.md` を読み込みます
2. まだ着手されていない（Pendingな）次のタスクを選択します
3. そのタスクのスコープに絞って実装（コーディング）を行います
4. 実装完了後、 `tasks.md` 内のタスクステータスを「完了（Done）」に更新します
5. 実装したコードの検証のため、 `/test` および `/review` への引き継ぎを促します

## メモ

- 一度に全てを作るのではなく、インクリメンタル（少しずつ）に実装し、常にレビュー可能な状態を保ちます
- 承認された要件や設計の範囲外の大幅な変更や、過剰な作り込み（Over-engineering）を防ぎます
- 事前に `/spec-tasks` でタスクの細分化と承認が完了している状態で実行するのが最も効果的です

## 次のステップ

- [`/test`](/docs/spec/test) - 実装の検証
- [`/review`](/docs/spec/review) - 品質管理とリグレッションレビュー
- [`/spec-status`](/docs/spec/status) - 全体の進捗ステータスを確認します
