# /code

`.specs/[feature-name]/tasks.md` に記載されたタスクのうち、未着手のものを上から順に実装していくコマンドです。

## 使い方

**Claude Code:**
```bash
/code user-authentication
```

**Antigravity:**
```bash
/code user-authentication
```

## 説明

`/code` は、 `/spec-tasks` でタスクリストを作成した後に実行する「実装フェーズ」のコマンドです。コードの変更範囲を小さく保ち、テストやレビューがしやすい状態を維持するため、一度に1つのタスクだけに集中して実装を行います。

## 実行時のフロー

1. `.specs/[feature-name]/tasks.md` を読み込みます
2. まだ着手されていない次のタスクを特定します
3. そのタスクの要求を満たす最小限のコード実装を行います
4. 実装後、 `/test [feature-name]` を実行してテストします
5. 問題がなければ `/review [feature-name]` を実行してレビューを受けます


## 期待される出力

`/code` コマンド実行後の一般的な状態は以下の通りです：
- 対象タスクのコード実装が完了している
- 関連するテストが `/test` コマンドで実行され、パスしている
- 品質・セキュリティのチェックが `/review` コマンドで実行され、問題がない

## 実行時のヒント

- 変更の差分（diff）を綺麗に保つため、必ず1回の実行で1つのタスクだけを実装するようにしてください
- `tasks.md` に書かれたタスクの順番通りに実装を進めましょう
- `/code` は、常に `/test` および `/review` とセットで実行する習慣をつけてください

## 次のステップ

- [`/test`](/docs/spec/test) - 実装の検証
- [`/review`](/docs/spec/review) - 品質管理とリグレッションレビュー
- [`/spec-status`](/docs/spec/status) - 全体の進捗ステータスを確認します
