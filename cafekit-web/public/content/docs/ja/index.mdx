# CafeKit ドキュメント

CafeKitへようこそ。CafeKitは、AIコーディングアシスタント（[Claude Code](https://claude.ai/code)、[Antigravity](https://antigravity.google/)）向けの、構造化された仕様駆動（spec-driven）開発ワークフローを提供するツールキットです。

## CafeKitとは

CafeKitは、8つのワークフローコマンドでAIコーディングアシスタントを拡張し、複雑な機能の開発やプロジェクトのドキュメント管理をガイドします。
行き当たりばったりのプロンプトを書く代わりに、CafeKitは「アイデアをプロダクト品質のコードへと確実に変えるための、再現性のあるプロセス」を提供します。

## なぜ仕様駆動開発（Spec-Driven Development）なのか？

従来のAI任せのコーディングでは、次のような問題がよく起こります：
- 要件が曖昧なことによる手戻りの発生
- 後半になって気付くエッジケースの考慮漏れ
- チャットのセッションをまたぐと文脈（コンテキスト）が失われる
- 場当たり的な実装による不整合

**CafeKitは、構造化されたワークフローを導入することでこれらの問題を解決します。**

**得られる成果:** 開発スピードの向上、バグの削減、そして質の高いドキュメントの維持。

## 主要なコンセプト

### Specs

**spec** はひとつの機能開発ごとに作られる、構造化された作業スペースです。以下が含まれます：

- `spec.json` - フェーズおよび承認ステータス
- `requirements.md` - EARSフォーマットの要件
- `design.md` - 技術設計
- `tasks.md` - タスクの細分化

Specsは `.specs/` に配置され、チーム開発において情報共有できるよう、Gitにコミットして管理します。

### ドキュメント（Documentation）

ドキュメント管理機能により、以下のファイルが自動的に生成・更新されます：

- `codebase-summary.md` - コードベースの概要
- `project-overview-pdr.md` - プロダクト要件
- `code-standards.md` - コーディング規約
- `system-architecture.md` - システムアーキテクチャ
- `design-guidelines.md` - UI/UXガイドライン
- `deployment-guide.md` - デプロイメントガイド
- `project-roadmap.md` - プロジェクトロードマップ

ドキュメントは `docs/` に配置され、AIアシスタントがプロジェクトの全体像を正確に把握するための知識ベースとして機能します。

## ユースケース

### こんなケースにおすすめです：

- **複雑な機能** - 認証、支払い、管理ダッシュボードの開発
- **新しいプロジェクト** - アーキテクチャの選定理由などをドキュメントに残したい場合
- **チームでのコラボレーション** - 仕様（Specs）がチーム全体の共通認識となる場合
- **長時間の作業** - AIとのチャットセッションを何回もまたぐような、長期にわたる開発作業

### 逆に、こういうケースなら不要です（普通にAIを使ってください）：

- 簡単なバグ修正 (`30分未満`)
- 文言の変更やタイポの修正
- ちょっとしたCSSの微調整
- ごく簡単なコードのリファクタリング
