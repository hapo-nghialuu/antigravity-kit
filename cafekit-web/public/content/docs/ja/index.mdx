# CafeKit ドキュメント

CafeKit は **Claude Code-first runtime bundle** です。spec-driven な開発フローに必要な workflow、agent、hook、runtime context を導入し、ad-hoc な prompting に頼らずに idea から verified implementation まで進められます。

## 対象ユーザー

CafeKit は次のようなケースに向いています。

- 単発の prompt ではなく、構造化された feature workflow が欲しい
- spec artifact を project に残したい
- task 単位で execution と verification を管理したい
- done を宣言する前に review と docs checkpoint を通したい

## コアループ

```text
Idea
  -> /hapo:brainstorm (unclear な場合)
  -> /hapo:specs
  -> /hapo:develop
  -> /hapo:test
  -> /hapo:code-review
```

よく使う補助 command:

- `/hapo:brainstorm <idea>` for scout-first ideation before a spec
- `/hapo:specs --validate <feature>`
- `/hapo:sync audit <feature>`
- `/hapo:generate-graph <request>`
- project documentation workflow 用の `/docs init` と `/docs update`

## CafeKit が入れるもの

インストール時に CafeKit は `.claude/` に runtime bundle を追加します。

```text
.claude/
├── skills/
├── agents/
├── hooks/
├── settings.json
├── runtime.json
├── status.cjs
└── CLAUDE.md
```

主な release surface:

- `/hapo:brainstorm`
- `/hapo:specs`
- `/hapo:develop`
- `/hapo:test`
- `/hapo:code-review`
- `/hapo:generate-graph`
