## サンプル一覧

### [User Authentication](/docs/examples/user-authentication)

### [Todo App API](/docs/examples/todo-app)

CRUD操作、フィルタリング、ソート機能を備えたTodoアプリ向けのREST API。基礎を学ぶのに最適な教材です。

**技術スタック:** REST API, CRUD, 初心者向け

## サンプルの構成

各サンプルには以下の内容が含まれています：

1. **要件定義 (Requirements)** - EARSフォーマットで記述された機能要件・非機能要件
2. **技術設計 (Design)** - アーキテクチャ、API規約、DBスキーマ、UIコンポーネント構成など
3. **タスク分割 (Tasks)** - 工数見積もりと優先順位が付けられた実装計画（スプリントプラン）
4. **実装メモ (Implementation notes)** - 重要な技術的決定や、参考となるコードスニペット

## これらサンプルの活用方法

### 学習リソースとして読む

サンプルを読み解くことで、以下のノウハウを吸収できます：
- 質の高い「要件」の書き方
- 優れた技術設計書の構成
- 大きな作業を適切なサイズのタスクに分解するコツ
- 開発における一般的なパターンやベストプラクティス

### テンプレートとして使い回す

サンプルのドキュメントをコピーし、自分のプロジェクトに合わせて書き換えてみましょう：

```bash
# 例のコンセプトから開始
/spec-init user-authentication-with-oauth

# サンプルの要件定義をベースにする
# 独自の要件に合わせて内容を書き換える
```

### 困った時のリファレンスとして

以下のような場面で迷ったら、いつでもこのサンプルに戻ってきて確認してください：
- セキュリティのベストプラクティス（User Authentication を参照）
- API設計パターン（Todo App を参照）
- 手持ちの作業をどうタスク分割すべきか迷った時
- ドキュメントの書き方の参考例が欲しい時
