## Catalog

| Skill | Use it for |
|---|---|
| `hapo:brainstorm` | spec 前の scout-first ideation。 |
| `hapo:specs` | requirements、research、design、task generation、validation。 |
| `hapo:develop` | approved spec tasks の implementation。 |
| `hapo:test` | unit、integration、build、UI、task-aware verification。 |
| `hapo:code-review` | regressions、security、contract drift の adversarial review。 |
| `hapo:sync` | `spec.json` と task markdown state の repair/audit。 |
| `hapo:debug` | evidence-first root-cause diagnosis。 |
| `hapo:hotfix` | diagnosis 後の small safe fix。 |
| `hapo:inspect` | codebase discovery と scoped file scouting。 |
| `impact-analysis` | blast-radius と regression scenario analysis。 |
| `hapo:research` | external technical research と source validation。 |
| `hapo:docs` | project docs、summaries、updates、as-is reconstruction。 |
| `hapo:generate-graph` | SVG/PNG technical diagrams。 |
| `hapo:git` | safe branch、commit、push、worktree operations。 |
| `hapo:frontend-design` | polished frontend redesign と visual execution。 |
| `hapo:frontend-development` | React/TypeScript frontend implementation patterns。 |
| `hapo:react-best-practices` | React/Next.js performance guidance。 |
| `hapo:ui-ux-pro-max` | UI/UX rules、accessibility、layout、motion、design intelligence。 |
| `hapo:web-testing` | Playwright、Vitest、k6、visual、a11y、performance testing。 |
| `hapo:agent-browser` | context-efficient browser automation snapshots。 |
| `hapo:chrome-devtools` | Puppeteer screenshots、console、ARIA checks。 |
| `hapo:ai-multimodal` | image、audio、video、OCR、transcript、document analysis。 |
| `hapo:backend-development` | APIs、auth、databases、services、security。 |
| `hapo:devops` | Cloudflare、Docker、GCP、Kubernetes、CI/CD。 |
| `hapo:mobile-development` | React Native、Flutter、SwiftUI、Kotlin、mobile UX。 |
| `hapo:docx` | Word creation、extraction、editing、comments、redlines。 |
| `hapo:pdf` | PDF extraction、generation、forms、merge、split。 |
| `hapo:pptx` | PowerPoint creation、editing、templates、slide generation。 |
| `hapo:xlsx` | spreadsheets、formulas、charts、analysis、recalculation。 |

## Routing rule

task に合う最小の skill を選びます。小さな fix に full spec workflow を強制せず、曖昧な request のまま code に入らないでください。
