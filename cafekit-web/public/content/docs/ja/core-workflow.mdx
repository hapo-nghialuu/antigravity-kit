## Main path

```text
/hapo:brainstorm         # intent または architecture が未解決なら optional
  -> /hapo:specs         # C1 -> plan.md + flat tasks -> adversarial review -> C2
  -> planning stop
  -> /hapo:develop       # new explicit invocation; one unblocked task
  -> /hapo:test          # smallest adequate real proof
  -> /hapo:code-review   # correctness, security, regression, contract drift
  -> /hapo:sync          # observed Status と inline Receipt のみ
  -> C3                  # user completion decision
```

Chat は source of truth ではありません。New work は `specs/<feature>/plan.md` と flat `task-NN-*.md` を使います。

## Contract and execution

`plan.md` は C1 scope、exclusions、acceptance criteria、dependencies、C2 decisions を記録します。各 task は one outcome、one `Status:`、ownership、dependencies、proof command、final inline `## Receipt` を持ちます。

Develop は mutation 前に real entrypoints と callers を scout。Runtime-facing work は actual route、command、UI mount、worker、service、API boundary から reachable になるまで incomplete です。

Named technology や runtime choice を黙って置換しません。Scope change は plan と user decision に戻します。

## Proof stack

<WorkflowProofStack />

Green command だけでは不十分です。Acceptance に関係する exact commands を実行し、zero tests と `NO_TESTS` は pass しません。Review finding は repair と reverify まで completion を block します。

## State ownership

<WorkflowStateRail />

Controller だけが task Status と canonical Receipt を更新します。Sync は observed state を reconcile できますが execution、approval、completion を捏造できません。

## Alternate routes

| Situation | Route |
|---|---|
| Evidence-backed answer | `/hapo:ask` |
| Scoped codebase discovery | `/hapo:scout` |
| Root cause unknown | `/hapo:debug` |
| Diagnosed bug repair | `/hapo:fix` |
| Existing system lacks reliable docs | `/hapo:docs --reconstruct <scope>` |
| Uncertain technical decision | `/hapo:research` |
| Explicit bounded numeric optimization | `/hapo:loop` |

Claude Code は `/hapo:*`、Codex CLI は native `$hapo-*` skills。OpenCode commands は historical 0.16 notes のみです。
