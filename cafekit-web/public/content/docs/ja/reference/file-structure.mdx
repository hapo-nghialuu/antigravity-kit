## 各ファイルの役割

### AI用設定ファイル

| ファイル | Claude | Antigravity | 目的 |
|------|--------|-------------|---------|
| `ROUTING.md` | ✅ | ❌ | Claude コマンドのルーティングルール |
| `rules/GEMINI.md` | ❌ | ✅ | Antigravityがこのワークスペースで動くためのルール定義 |

### 仕様（Spec）関連ファイル

| ファイル | 説明 | 生成コマンド |
|------|-------------|------------|
| `spec.json` | フェーズと承認ステータス | `/spec-init` |
| `requirements.md` | EARSフォーマットで書かれた要件定義 | `/spec-requirements` |
| `design.md` | 技術設計（Technical design） | `/spec-design` |
| `tasks.md` | 実装タスクの分割リスト（スプリントプラン） | `/spec-tasks` |

### ドキュメントファイル

| ファイル | 説明 | 生成・更新コマンド |
|------|-------------|------------|
| `codebase-summary.md` | 技術スタックとプロジェクト構造 | `/docs init`, `/docs update` |
| `project-overview-pdr.md` | プロダクト要件 | `/docs init`, `/docs update` |
| `code-standards.md` | コーディング規約 | `/docs init`, `/docs update` |
| `system-architecture.md` | システムアーキテクチャの解説 | `/docs init`, `/docs update` |
| `design-guidelines.md` | UI/UXガイドライン | `/docs init`, `/docs update` |
| `deployment-guide.md` | デプロイメントガイド | `/docs init`, `/docs update` |
| `project-roadmap.md` | 今後の開発ロードマップ | `/docs init`, `/docs update` |

## Gitの管理方針

### Gitにコミットするもの
- `.specs/` (すべてのspec関連ファイル)
- `.claude/` または `.agent/` ワークフローの設定
- `docs/` (ドキュメント)

### Gitから除外（Ignore）するもの
- `.backups/` (自動生成されるバックアップであり、ファイルサイズが大きくなるため)
- `repomix-output.xml` (コマンドでいつでも再生成可能なため)

### `.gitignore` の設定例

```gitignore
# CafeKit backups
docs/.backups/
repomix-output.xml
```

## プラットフォームの乗り換え

### Claude CodeからAntigravityへ
```bash
# specとdocsの退避（バックアップ）
cp -r .specs .specs-backup
cp -r docs docs-backup

# Antigravity版のインストール
npx @haposoft/cafekit
# メニューからAntigravityを選択

# 退避したファイルを元に戻す
cp -r .specs-backup/* .specs/
cp -r docs-backup/* docs/
```

### AntigravityからClaude Codeへ
```bash
# specとdocsの退避（バックアップ）
cp -r .specs .specs-backup
cp -r docs docs-backup

# Claude Code版のインストール
npx @haposoft/cafekit
# メニューからClaude Codeを選択

# 退避したファイルを元に戻す
cp -r .specs-backup/* .specs/
cp -r docs-backup/* docs/
```

生成された仕様書（spec）や各種ドキュメント（docs）はプラットフォームに依存しないため、ファイルを移動するだけでそのまま引き継げます。
