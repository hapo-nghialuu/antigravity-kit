# Claude Code

Claude Code環境でCafeKit Specを使用するための総合ガイド。

## インストール

```bash
npx @haposoft/cafekit-spec
```

インストーラーが起動したら、メニューから **Claude Code** を選択してください。

## ファイル構造

インストールが完了すると、CafeKit Specは以下のワークフローファイルを `.claude/` ディレクトリ配下に生成します：

```
.claude/
├── commands/
│   ├── spec-init.md
│   ├── spec-requirements.md
│   ├── spec-design.md
│   ├── spec-tasks.md
│   ├── spec-status.md
│   ├── code.md
│   ├── test.md
│   ├── review.md
│   └── docs.md
├── agents/
│   ├── tester.md
│   ├── code-reviewer.md
│   ├── fullstack-developer.md
│   └── debugger.md
├── skills/
│   └── specs/
└── ROUTING.md
```

## コマンド一覧

### spec ワークフロー
| コマンド | 説明 |
|---------|-------------|
| `/spec-init` | 新しい仕様（spec）の初期化 |
| `/spec-requirements` | 要件（要件定義）のヒアリングと生成 |
| `/spec-design` | 技術設計書（アーキテクチャ・API等）の生成 |
| `/spec-tasks` | 実装作業を細分化したタスクの生成 |
| `/code` | スプリントプランから未着手のタスクを1つ実装 |
| `/test` | テストの実行と、失敗時の原因の要約 |
| `/review` | コードの正当性やセキュリティのレビュー |
| `/spec-status` | 現在の進捗状況（ステータス）の表示 |

### ドキュメント（Documentation）ワークフロー
| コマンド | 説明 |
|---------|-------------|
| `/docs init` | AI開発の土台となるプロジェクトドキュメントの初期化 |
| `/docs update` | コードに大きな変更があった後のドキュメント更新 |

## 使用例

### 機能開発を開始する

```
> /spec-init payment-gateway
```

### タスクを実装する

```
> /code payment-gateway
> /test
> /review
```

### プロジェクトドキュメントの管理

```
> /docs init
> /docs update
```

## Antigravityとの違い

| | Claude Code | Antigravity |
|---|---|---|
| ワークフローのディレクトリ | `.claude/commands/` | `.agent/workflows/` |
| Agentディレクトリ | `.claude/agents/` | `.agent/agents/` |
| ルーティングルールファイル | `.claude/ROUTING.md` | `.agent/rules/GEMINI.md` |
| コマンドトリガー | `/...` | `/...` または `@...` |

## トラブルシューティング

### コマンドが表示されない
```bash
ls -la .claude/commands/
```

### コマンドの実行に関する問題
- Claude Codeを再起動する
- コマンドファイルが適切なフロントマター（frontmatter）を持つ `.md` 形式であるか確認する
- インストーラーを再度実行する: `npx @haposoft/cafekit-spec`
