# Platform Guides

CafeKitは、複数の主要なAIコーディングアシスタントに対応しています。お使いのプラットフォームを選択してください：

## 対応プラットフォーム

- **[Claude Code](/docs/platforms/claude)** - Anthropic提供のClaude Code CLI
- **[Antigravity](/docs/platforms/antigravity)** - Google提供のAntigravity IDE

どちらの環境でも基本的な仕様（spec）ワークフローのコマンドは共通ですが、コマンドの呼び出し方や使える機能に若干の違いがあります。
