## Claude Code

Claude Code には full runtime が入ります。

- `.claude/skills`
- `.claude/agents`
- `.claude/hooks`
- `.claude/settings.json`
- `.claude/runtime.json`
- `.claude/status.cjs`
- root `CLAUDE.md`

## OpenCode

OpenCode には次が入ります。

- `.opencode/commands`
- `.opencode/agents`
- `.opencode/cafekit.json`
- root `AGENTS.md`
- merged `opencode.json`
- shared `.claude/skills`, `.claude/rules`, `.claude/scripts`, `.claude/references`, `.claude/runtime.json`

OpenCode commands は意図的に `hapo:` を省略します。

## Future platforms

Cursor は current installer の runtime target ではありません。
