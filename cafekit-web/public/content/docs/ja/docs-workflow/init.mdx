# /docs init

AIやチームメンバーがプロジェクトを理解するための「基準（ベースライン）」となるドキュメント群を作成します。

## コマンドの概要

このコマンドは、現在のコード全体を解析し、AIコーディングアシスタントが最も読みやすい形に最適化されたドキュメント一式を自動生成します。（一部のプラットフォームでは `/docs-init` となります）

## 裏側で行われること

コマンドを実行すると、以下の順序で処理が進みます：

1. **repomix** を実行し、全コードを1つの `repomix-output.xml` ファイルに圧縮・出力します。
2. AIがこのXMLファイルを読み込み、プロジェクトの技術スタック（例：Reactアプリなのか、Node.jsバックエンドなのか等）を特定します。
3. コードの中からアーキテクチャのパターン、コーディング規約、デプロイ手順などの情報を抽出します。
4. 最後に、使用中のプラットフォームに合わせて必要なドキュメントファイル（ `CLAUDE.md` や `AGENTS.md` など）を生成します。

## 出力されるファイル

お使いのプラットフォームによって出力結果が異なります：

### Claude Code

- プロジェクトルートの `CLAUDE.md`
- `docs/` フォルダとその中身：
  - `codebase-summary.md`
  - `project-overview-pdr.md`
  - `code-standards.md`
  - `system-architecture.md`
  - `design-guidelines.md`
  - `deployment-guide.md`
  - `project-roadmap.md`

### Antigravity

- `.agent/rules/AGENTS.md`

## 使うべきタイミング

- CafeKitをインストールし、いざ具体的な機能開発を始める前の「一歩目」として、まずこのコマンドを実行してください。
- すでに開発が進んでいる既存プロジェクトに途中からAIを導入する場合にも、最初のコンテキスト共有として非常に有効です。
