# インストール

project root で CafeKit をインストールします。

```bash
npx @haposoft/cafekit
```

## 前提条件

- Node.js 18+
- Claude Code project
- `.claude/` を管理できる writable な project root

任意:

- `/docs init` や `/docs update` を使うなら `repomix`

```bash
npm install -g repomix
```

## Installer が行うこと

CafeKit は Claude runtime bundle をインストールして管理します。

```text
.claude/
├── skills/
├── agents/
├── hooks/
├── settings.json
├── runtime.json
├── status.cjs
└── CLAUDE.md
```

あわせて次の command surface を入れます。

- `/hapo:specs`
- `/hapo:develop`
- `/hapo:test`
- `/hapo:code-review`
- `/hapo:generate-graph`

## インストール確認

Claude Code を project で開き、次を実行します。

```bash
/hapo:specs Build a small feature from a clear problem statement
```

CafeKit が正しく入っていれば、Claude はこれを plain text ではなく spec workflow として処理します。

## 既存インストールの更新

managed bundle を更新するには:

```bash
npx @haposoft/cafekit --upgrade
```

## 注意

- CafeKit は **Claude Code-first** です。
- Antigravity と Cursor は予定されていますが、まだ利用できません。
- `/docs init` と `/docs update` は補助 workflow であり、core install path の必須要素ではありません。
