# Installation

CafeKitをインストールして、プロジェクトに仕様駆動開発（spec-driven development）を導入しましょう。

## 前提条件

インストールの前に、以下の環境が整っていることを確認してください：

- **Node.js 18+** - CLIの実行に必要
- **AIコーディングアシスタント** - CafeKitは [Claude Code](https://claude.ai/code) または [Antigravity](https://antigravity.google/) と連携します
- **推論モデル（Reasoning Model）** - 計画フェーズ（`spec-*`）でより精度の高い出力を得るため、**Claude Opus 4.5 (Thinking Mode)** などの推論モデルの使用をお勧めします。
- **Git** - バージョン管理と更新用
- **repomix** - コードベース全体をAI解析用のXMLファイルに圧縮する `/docs init` コマンドで必要になります：
  ```bash
  npm install -g repomix
  # または: pnpm install -g repomix
  # または: yarn global add repomix
  ```

## 対応プラットフォーム

CafeKitは、複数のAIコーディングアシスタントプラットフォームをサポートしています：

| プラットフォーム | コマンドフォーマット | ステータス |
|----------|---------------|--------|
| **[Claude Code](https://claude.ai/code)** | `/spec-init` | 利用可能 |
| **[Antigravity](https://antigravity.google/)** | `/spec-init` (または `@spec-init`) | 利用可能 |

インストールプロセス中にプラットフォームを自動検出し、環境に合った適切なコマンドフォーマットがインストールされます。

## CafeKitのインストール

プロジェクトのルートディレクトリでインストールコマンドを実行します：

```bash
npx @haposoft/cafekit
```

インストーラーが起動し、プラットフォームの選択を求められます：

```
? Select your AI coding assistant platform:
  ❯ Claude Code
    Antigravity
```

このコマンドは以下の処理を実行します：
- プロジェクト構造の検出
- コアコマンドセットのインストール（`/spec-init`, `/spec-requirements`, `/spec-design`, `/spec-tasks`, `/spec-status`, `/code`, `/test`, `/review`）
- 仕様駆動開発を行うためのワークスペースのセットアップ

### ドキュメントのセットアップ（Claude Code のみ）

**前提条件:** [repomix](https://github.com/yamadashy/repomix) がローカル環境にグローバルインストールされていることを確認してください：
```bash
npm install -g repomix
```

インストール後、`/docs` コマンドを使用してプロジェクトドキュメントを生成します：

```bash
# プロジェクトドキュメントのベースとなる情報を初期化する
/docs init

# または既存のドキュメントを更新する
/docs update
```

**repomixの役割:** コードベースを `repomix-output.xml` に圧縮し、AIがプロジェクト構造を正確に分析し、ドキュメントを生成できる状態にします。

これにより以下が作成されます：
- プラットフォームのコンテキストファイル（`CLAUDE.md` または `.agent/rules/AGENTS.md`）
- 以下の内容を含む `docs/` フォルダ：
  - `codebase-summary.md`
  - `project-overview-pdr.md`
  - `code-standards.md`
  - `system-architecture.md`
  - `design-guidelines.md`
  - `deployment-guide.md`
  - `project-roadmap.md`

**注:** `/docs` は `/docs init` および `/docs update` コマンドとして提供されます。これらはAIアシスタントのコンテキスト機能に依存して動作します。

## インストールの確認

AIコーディングアシスタントを開き、お使いのプラットフォームに応じた初期化（init）コマンドを入力します：

### Claude Code
```
/spec-init
```

### Antigravity
```
/spec-init
# または
@spec-init
```

specの初期化ワークフローが開始されるはずです。

## トラブルシューティング

### コマンドが見つからない

specコマンドが機能しない場合：

1. **ファイルの配置を確認** - 以下の正しいフォルダにファイルが存在するか確認してください：
   - Claude Code: `.claude/commands/`
   - Antigravity: `.agent/workflows/`
2. **AIアシスタントの再起動** - アシスタントによっては、新しいコマンドを読み込ませるために再起動が必要な場合があります
3. **ファイル形式の確認** - コマンドファイルは、適切なフロントマター（frontmatter）を持つ `.md` 形式である必要があります
4. **プラットフォーム選択の確認** - インストーラーを再実行し、正しいプラットフォームを選択したか確認してください

### ディレクトリが間違っている場合

もしCafeKitが意図しないディレクトリにインストールされてしまった場合は、手動でフォルダを作成して再実行してください：

```bash
# Claude Codeの場合 - .claude/commands/ が存在することを確認
mkdir -p .claude/commands/

# Antigravityの場合 - .agent/workflows/ が存在することを確認
mkdir -p .agent/workflows/

# インストーラーを再実行
npx @haposoft/cafekit
```
