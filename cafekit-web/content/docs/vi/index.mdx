# Tài liệu CafeKit Spec

Chào mừng đến với CafeKit Spec - một quy trình phát triển hướng spec có cấu trúc dành cho các trợ lý lập trình AI ([Claude Code](https://claude.ai/code), [Antigravity](https://antigravity.google/)).

## CafeKit Spec là gì?

CafeKit Spec mở rộng các trợ lý lập trình AI với 6 lệnh quy trình mạnh mẽ hướng dẫn bạn xây dựng các tính năng phức tạp:

1. **Khởi tạo (Initialize)** - Tạo workspace spec
2. **Yêu cầu (Requirements)** - Nắm bắt những gì bạn cần
3. **Thiết kế (Design)** - Định nghĩa kiến trúc
4. **Tasks** - Chia nhỏ việc thực hiện
5. **Thực hiện (Implement)** - Xây dựng với hướng dẫn của AI
6. **Trạng thái (Status)** - Theo dõi tiến độ

Thay vì các prompt ngẫu hứng, CafeKit Spec cung cấp cho bạn một quy trình lặp lại để biến ý tưởng thành code sản phẩm (production code).

## Tại sao chọn Spec-Driven Development?

AI coding truyền thống thường dẫn đến:
- Yêu cầu không đầy đủ gây ra việc phải làm lại
- Các trường hợp biên (edge cases) bị phát hiện muộn
- Mất ngữ cảnh giữa các phiên làm việc
- Triển khai không nhất quán

**CafeKit Spec giải quyết điều này** bằng cách tạo ra một quy trình có cấu trúc.

**Kết quả:** Phát triển nhanh hơn, ít lỗi hơn, tài liệu tốt hơn.

## Bắt đầu

### 1. Cài đặt CafeKit Spec

```bash
npx @haposoft/cafekit-spec
```

Cài đặt 6 lệnh quy trình spec vào trợ lý lập trình AI của bạn.

### 2. Tạo Spec đầu tiên của bạn

Làm theo hướng dẫn bắt đầu nhanh tương tác của chúng tôi:

```bash
/spec-init my-first-feature
/spec-requirements my-first-feature
```

AI hướng dẫn bạn xác định yêu cầu, thiết kế kiến trúc và chia nhỏ các task.

### 3. Thực hiện với hướng dẫn của AI

```bash
/spec-impl my-first-feature
```

AI đọc spec của bạn và giúp bạn xây dựng từng task một, với sự xác minh ở mỗi bước.

[Đọc Hướng dẫn Bắt đầu nhanh đầy đủ](/docs/getting-started/quickstart)

## Các khái niệm cốt lõi

### Specs

Một **spec** là một workspace có cấu trúc cho một tính năng. Nó chứa:

- `requirements.md` - Bạn đang xây dựng cái gì và tại sao
- `design.md` - Kiến trúc kỹ thuật và các hợp đồng (contracts)
- `tasks/sprint-1.md` - Phân chia task theo mức độ ưu tiên
- `status.md` - Tiến độ thực hiện

Specs nằm trong `.specs/` và được commit vào Git để team cùng phối hợp.

### Các lệnh quy trình (Workflow Commands)

CafeKit Spec thêm 6 lệnh slash vào trợ lý lập trình AI của bạn:

| Lệnh | Mục đích |
|---------|---------|
| `/spec-init` | Tạo workspace spec |
| `/spec-requirements` | Thu thập yêu cầu thông qua hỏi đáp Socratic |
| `/spec-design` | Tạo tài liệu thiết kế kỹ thuật |
| `/spec-tasks` | Chia nhỏ thành các task thực hiện |
| `/spec-impl` | Thực hiện task với hướng dẫn của AI |
| `/spec-status` | Xem tiến độ và các vấn đề chặn (blockers) |

## Trường hợp sử dụng

### Hoàn hảo cho:

- **Các tính năng phức tạp** - Xác thực, thanh toán, bảng điều khiển admin
- **Dự án mới** - Các quyết định kiến trúc cần tài liệu
- **Hợp tác nhóm** - Specs cung cấp ngữ cảnh được chia sẻ
- **Công việc dài hạn** - Theo dõi tiến độ qua nhiều phiên làm việc

### Không cần thiết cho:

- Sửa lỗi đơn giản (&lt;30 phút)
- Thay đổi nội dung hoặc sửa lỗi chính tả
- Điều chỉnh CSS nhỏ
- Tái cấu trúc (refactor) nhỏ nhặt
