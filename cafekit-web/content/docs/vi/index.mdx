## CafeKit Spec là gì?

CafeKit Spec mở rộng các trợ lý lập trình AI với 8 lệnh quy trình mạnh mẽ hướng dẫn bạn xây dựng các tính năng phức tạp và quản lý tài liệu dự án.
Thay vì các prompt ngẫu hứng, CafeKit Spec cung cấp cho bạn một quy trình lặp lại để biến ý tưởng thành code sản phẩm.

## Tại sao chọn Spec-Driven Development?

AI coding truyền thống thường dẫn đến:
- Yêu cầu không đầy đủ gây ra việc phải làm lại
- Các trường hợp biên (edge cases) bị phát hiện muộn
- Mất ngữ cảnh giữa các phiên làm việc
- Triển khai không nhất quán

**CafeKit Spec giải quyết điều này** bằng cách tạo ra một quy trình có cấu trúc.

**Kết quả:** Phát triển nhanh hơn, ít lỗi hơn, tài liệu tốt hơn.

## Các khái niệm cốt lõi

### Specs

Một **spec** là một workspace có cấu trúc cho một tính năng. Nó chứa:

- `spec.md` - Tổng quan feature
- `requirements.md` - Yêu cầu EARS format
- `design.md` - Thiết kế kỹ thuật
- `tasks.md` - Phân chia task
- `implementation.md` - Tiến độ thực hiện

Specs nằm trong `specs/` và được commit vào Git để team cùng phối hợp.

### Documentation

Hệ thống docs tự động tạo:

- `codebase-summary.md` - Tổng quan codebase
- `project-overview-pdr.md` - Yêu cầu sản phẩm
- `code-standards.md` - Quy ước coding
- `system-architecture.md` - Kiến trúc hệ thống
- `design-guidelines.md` - Nguyên tắc UI/UX
- `deployment-guide.md` - Hướng dẫn triển khai
- `project-roadmap.md` - Lộ trình dự án

Docs nằm trong `docs/` và giúp AI assistant hiểu rõ hơn về dự án.

## Trường hợp sử dụng

### Hoàn hảo cho:

- **Các tính năng phức tạp** - Xác thực, thanh toán, bảng điều khiển admin
- **Dự án mới** - Các quyết định kiến trúc cần tài liệu
- **Hợp tác nhóm** - Specs cung cấp ngữ cảnh được chia sẻ
- **Công việc dài hạn** - Theo dõi tiến độ qua nhiều phiên làm việc

### Không cần thiết cho:

- Sửa lỗi đơn giản (`<30 phút`)
- Thay đổi nội dung hoặc sửa lỗi chính tả
- Điều chỉnh CSS nhỏ
- Tái cấu trúc (refactor) nhỏ nhặt
