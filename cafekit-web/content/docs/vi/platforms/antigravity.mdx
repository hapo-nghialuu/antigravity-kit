# Antigravity

Hướng dẫn đầy đủ cho việc sử dụng CafeKit Spec với Antigravity - AI assistant framework từ Google.

## Cài đặt

```bash
npx @haposoft/cafekit-spec
```

Chọn **Antigravity** trong menu cài đặt.

## Cấu trúc File

Sau khi cài đặt, các file được tạo trong thư mục `.agent/`:

```
.agent/
├── AGENTS.md                 # AI quick reference
├── GEMINI.md                 # Gemini-specific context
├── ARCHITECTURE.md           # Architecture docs
├── CONVENTIONS.md            # Platform conventions
├── agents/
│   ├── spec-init.json        # spec-init agent
│   ├── spec-requirements.json
│   ├── spec-design.json
│   ├── spec-tasks.json
│   ├── spec-impl.json
│   ├── spec-status.json
│   ├── docs-init.json
│   └── docs-update.json
├── skills/
│   └── ...                   # 40+ reusable skills
└── workflows/
    ├── spec_init.yaml
    ├── spec_requirements.yaml
    ├── spec_design.yaml
    ├── spec_tasks.yaml
    ├── spec_impl.yaml
    ├── spec_status.yaml
    ├── docs_init.yaml
    └── docs_update.yaml
```

## Command Syntax

Tất cả commands trong Antigravity sử dụng **dấu gạch dưới** (underscores):

### Spec Workflows
| Command | Mô tả |
|---------|-------|
| `/spec_init` | Khởi tạo spec mới |
| `/spec_requirements` | Phân tích yêu cầu |
| `/spec_design` | Thiết kế kỹ thuật |
| `/spec_tasks` | Chia nhỏ task |
| `/spec_impl` | Triển khai code |
| `/spec_status` | Kiểm tra tiến độ |

### Documentation Workflows
| Command | Mô tả |
|---------|-------|
| `/docs_init` | Khởi tạo documentation |
| `/docs_update` | Cập nhật documentation |

## Files Đặc biệt

### AGENTS.md
File reference nhanh cho AI:

```markdown
# Project Context

## Agents
- spec_init - Initialize feature spec
- spec_impl - Implement tasks
...

## Skills
- file_read, file_write, file_edit
- task_create, task_update
...
```

### GEMINI.md
Context đặc biệt cho Gemini model:

```markdown
# Gemini Configuration

## Model Settings
- Temperature: 0.2
- Max tokens: 8000

## Context Window
- Priority: AGENTS.md > GEMINI.md > codebase
```

### ARCHITECTURE.md
Mô tả kiến trúc framework:

```markdown
# Antigravity Architecture

## Agent System
- Specialized agents per workflow
- Skills-based composition

## Workflow Engine
- YAML-defined workflows
- State management
```

## Ví dụ sử dụng

### Khởi tạo feature mới

```
> /spec_init

Feature name: payment-gateway
Description: Tích hợp cổng thanh toán Stripe
...
```

### Triển khai từng task

```
> /spec_impl

Implement task: 3
Feature: payment-gateway
...
```

### Cập nhật documentation

```
> /docs_update

Cập nhật docs sau khi thêm Stripe integration
```

## Khác biệt với Claude Code

| | Antigravity | Claude Code |
|---|---|---|
| **Syntax** | Underscores (`/spec_init`) | Hyphens (`/spec-init`) |
| **Directory** | `.agent/` | `.claude/` |
| **Config file** | `AGENTS.md` | `CLAUDE.md` |
| **Extra files** | `GEMINI.md`, `ARCHITECTURE.md` | `ROUTING.md` |
| **Agent system** | Multiple specialized agents | Single Claude instance |
| **Skills** | 40+ reusable skills | Built-in capabilities |

## Multi-Agent System

Antigravity sử dụng nhiều specialized agents:

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  spec_init  │────▶│ spec_design │────▶│  spec_impl  │
│    agent    │     │    agent    │     │    agent    │
└─────────────┘     └─────────────┘     └─────────────┘
      │                                       │
      ▼                                       ▼
┌─────────────┐                         ┌─────────────┐
│  Codebase   │◀────────────────────────│   skills    │
│   Context   │                         │  (40+ tools)│
└─────────────┘                         └─────────────┘
```

Mỗi agent có:
- Prompt template riêng
- Skill set phù hợp
- Context window optimized

## Tips

1. **Dùng skills**: Antigravity có 40+ reusable skills
2. **Agent routing**: Hệ thống tự động chọn agent phù hợp
3. **GEMINI.md**: Customize cho Gemini model
4. **Workflow YAML**: Có thể edit workflows trực tiếp

## Troubleshooting

### Commands không hiển thị
```bash
# Kiểm tra cài đặt
ls -la .agent/workflows/
```

### AGENTS.md không được đọc
- Đảm bảo file ở root: `./AGENTS.md`
- Kiểm tra Antigravity configuration

### Lỗi khi chạy command
- Kiểm tra agent definitions
- Chạy lại installer: `npx @haposoft/cafekit-spec`
