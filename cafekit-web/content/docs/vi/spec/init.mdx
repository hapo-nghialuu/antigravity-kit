# /spec-init

Khởi tạo file đặc tả ban đầu cho một tính năng mới.

## Sử dụng

**Claude Code:**
```
/spec-init
```

**Antigravity:**
```
/spec_init
```

## Mô tả

Lệnh này tạo ra file `specs/[feature-name]/spec.md` với cấu trúc chuẩn. Đây là bước đầu tiên trong Spec-Driven Development.

## Quy trình

1. **Nhập tên feature**: VD: "user-authentication", "payment-gateway"
2. **Mô tả ngắn**: Tóm tắt mục đích của feature
3. **Tầm quan trọng**: Tại sao feature này cần thiết
4. **Mục tiêu**: Những gì cần đạt được
5. **Phạm vi**: In scope và Out of scope
6. **Giả định**: Những điều giả định trước khi bắt đầu

## Output

File `specs/[feature-name]/spec.md` được tạo với nội dung:

```markdown
# Feature Spec: [Feature Name]

## 1. Overview
Mô tả tổng quan về feature...

## 2. Goals
- Goal 1
- Goal 2

## 3. Scope
### In Scope
- ...

### Out of Scope
- ...

## 4. Assumptions
- ...
```

## Ví dụ

```
> /spec-init

Feature name: user-authentication
Description: Hệ thống xác thực ngườì dùng với JWT
...

✅ Created: specs/user-authentication/spec.md
```

## Lưu ý

- Tên feature nên dùng `kebab-case` (vd: `user-authentication`)
- File này sẽ được cập nhật trong các bước sau
- Có thể chỉnh sửa thủ công sau khi tạo

## Bước tiếp theo
