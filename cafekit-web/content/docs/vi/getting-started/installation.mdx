# Cài đặt

Cài đặt CafeKit Spec và bắt đầu sử dụng quy trình phát triển theo spec (spec-driven development) trong dự án của bạn.

## Yêu cầu

Trước khi cài đặt, hãy đảm bảo bạn có:

- **Node.js 18+** - Yêu cầu để chạy CLI
- **Trợ lý lập trình AI** - CafeKit Spec hoạt động với [Claude Code](https://claude.ai/code) hoặc [Antigravity](https://antigravity.google/)
- **Git** - Để quản lý phiên bản và cập nhật

## Khả năng tương thích nền tảng

CafeKit Spec hỗ trợ nhiều nền tảng trợ lý lập trình AI:

| Nền tảng | Định dạng lệnh | Trạng thái |
|----------|---------------|--------|
| **[Claude Code](https://claude.ai/code)** | `/spec-init` | Khả dụng |
| **[Antigravity](https://antigravity.google/)** | `/spec-init` (hoặc `@spec-init`) | Khả dụng |

Quá trình cài đặt sẽ tự động phát hiện nền tảng của bạn và cài đặt định dạng lệnh phù hợp.

## Cài đặt CafeKit Spec

Chạy lệnh cài đặt tại thư mục gốc của dự án:

```bash
npx @haposoft/cafekit-spec
```

Bộ cài đặt sẽ yêu cầu bạn chọn nền tảng:

```
? Select your AI coding assistant platform:
  ❯ Claude Code
    Antigravity
```

Lệnh này sẽ:
- Phát hiện cấu trúc dự án của bạn
- Cài đặt 6 lệnh workflow spec vào thư mục lệnh của nền tảng
- Cấu hình workspace cho quy trình phát triển theo spec

## Những gì được cài đặt

Sau khi chạy lệnh cài đặt, bạn sẽ có 6 lệnh workflow spec trong thư mục lệnh của nền tảng:

### Claude Code
```
.claude/commands/
├── spec-init.md           # Khởi tạo spec mới
├── spec-requirements.md   # Thu thập yêu cầu
├── spec-design.md         # Tạo tài liệu thiết kế
├── spec-tasks.md          # Tạo danh sách task
├── spec-impl.md           # Hướng dẫn implement
└── spec-status.md         # Theo dõi tiến độ
```

### Antigravity
```
.agent/commands/
├── spec-init.md           # Khởi tạo spec mới
├── spec-requirements.md   # Thu thập yêu cầu
├── spec-design.md         # Tạo tài liệu thiết kế
├── spec-tasks.md          # Tạo danh sách task
├── spec-impl.md           # Hướng dẫn implement
└── spec-status.md         # Theo dõi tiến độ
```

## Xác nhận cài đặt

Mở trợ lý lập trình AI của bạn và gõ lệnh init cho nền tảng tương ứng:

### Claude Code
```
/spec-init
```

### Antigravity
```
/spec-init
# hoặc
@spec-init
```

Bạn sẽ thấy workflow khởi tạo spec bắt đầu.

## Khắc phục sự cố

### Không tìm thấy lệnh

Nếu các lệnh spec không hoạt động:

1. **Kiểm tra vị trí file** - Đảm bảo các file nằm đúng thư mục:
   - Claude Code: `.claude/commands/`
   - Antigravity: `.agent/commands/`
2. **Khởi động lại trợ lý AI** - Một số công cụ cần khởi động lại để phát hiện lệnh mới
3. **Kiểm tra định dạng file** - Các lệnh phải là file `.md` với frontmatter hợp lệ
4. **Kiểm tra lựa chọn nền tảng** - Chạy lại bộ cài đặt và xác nhận đã chọn đúng nền tảng

### Sai thư mục

Nếu CafeKit cài đặt sai thư mục, bạn có thể di chuyển file thủ công:

```bash
# Cho Claude Code - đảm bảo .claude/commands/ tồn tại
mkdir -p .claude/commands/

# Cho Antigravity - đảm bảo .agent/commands/ tồn tại
mkdir -p .agent/commands/

# Chạy lại bộ cài đặt
npx @haposoft/cafekit-spec
```
