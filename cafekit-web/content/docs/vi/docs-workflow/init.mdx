# /docs init

Khởi tạo toàn bộ tài liệu dự án để AI assistant có thể hiểu và làm việc hiệu quả.

## Sử dụng

**Claude Code:**
```
/docs init
/docs init --focus=src,api
```

**Antigravity:**
```
/docs_init
/docs_init --focus=src,api
```

### Flags tùy chọn

| Flag | Mô tả | Ví dụ |
|------|-------|-------|
| `--focus=dir1,dir2` | Tập trung vào các thư mục cụ thể | `--focus=src,components` |
| `--dir=./path` | Chỉ định thư mục target | `--dir=./my-project` |

## Mô tả

Lệnh này quét toàn bộ codebase và tạo 7 file documentation chuẩn hóa, cùng với file reference cho AI.

## Output

### Documentation Files

```
docs/
├── codebase-summary.md      # Tổng quan codebase
├── project-overview-pdr.md  # Product requirements
├── code-standards.md        # Coding conventions
├── system-architecture.md   # Architecture docs
├── design-guidelines.md     # UI/UX guidelines
├── deployment-guide.md      # Deployment guide
└── project-roadmap.md       # Project roadmap
```

### AI Context Files

```
# Cho Antigravity:
.agent/
├── AGENTS.md                # Quick reference cho AI
├── rules/
│   └── 001-project.md       # Project context
└── ...

# Cho Claude Code:
.claude/
├── CLAUDE.md                # Quick reference cho AI
├── commands/
└── ...
```

### repomix-output.xml

File AI context được tạo ở root:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<repository
  name="project-name"
  description="Auto-generated from codebase"
>
  <directory structure="...">
    ...
  </directory>
  <files>
    ...
  </files>
</repository>
```

## Nội dung từng file

### codebase-summary.md
- Tech stack (frameworks, libraries)
- Project structure
- Key directories
- Dependencies

### project-overview-pdr.md

- User personas
- Core features
- Success metrics

### code-standards.md

- File organization

### system-architecture.md

### design-guidelines.md

- Build process

## Quy trình

```
1. Scan codebase
   └── AI đọc tất cả files quan trọng

2. Analyze structure
   └── Phân tích architecture, patterns

3. Generate docs
   └── Tạo 7 markdown files

4. Create AI reference
   └── AGENTS.md hoặc CLAUDE.md

5. Export repomix
   └── repomix-output.xml cho AI context
```

## Thờì gian chạy

- **Small project** (< 100 files): ~1-2 phút
- **Medium project** (100-1000 files): ~3-5 phút
- **Large project** (> 1000 files): ~5-10 phút

## Lưu ý

- `/docs init` sẽ **ghi đè** file nếu đã tồn tại
- Backup được tạo tự động trước khi ghi đè
- Nên review và edit docs sau khi tạo

## Xử lý Lỗi

| Tình huống | Hành động |
|------------|-----------|
| `docs/` đã tồn tại | Hỏi: Overwrite / Merge / Skip |
| Thiếu `package.json` | Yêu cầu user cung cấp project type |
| `repomix` chưa cài | Cảnh báo, tiếp tục với manual analysis |
| Không có quyền ghi | Báo lỗi path, gợi ý fix |

## Bước tiếp theo

- Review các file trong `docs/`
- Edit để bổ sung thông tin cụ thể
- Chạy [`/docs update`](/docs/docs-workflow/update) khi code thay đổi
