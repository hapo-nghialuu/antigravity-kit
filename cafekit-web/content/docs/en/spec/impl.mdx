# /spec-impl

Implement code for one or more tasks from tasks.md.

## Usage

**Claude Code:**
```
/spec-impl
```

**Antigravity:**
```
/spec_impl
```

## Description

This command guides AI to implement code for incomplete tasks in `tasks.md`. After implementation, updates `implementation.md` with status.

## Process

1. AI reads `tasks.md` to see incomplete tasks
2. User selects task to implement (or AI suggests)
3. AI implements code according to specification
4. Updates `implementation.md` with:
   - Completed tasks
   - Files created/modified
   - Implementation notes

## Usage Methods

### Implement specific task

```
> /spec-impl

Implement task: 3
Feature: user-authentication
...
```

### Implement multiple tasks

```
> /spec-impl

Implement tasks: 1, 2, 3
Feature: user-authentication
...
```

### AI selects next task

```
> /spec-impl

Feature: user-authentication
Auto-select next task: yes
...
```

## Output

File `specs/[feature-name]/implementation.md` is created/updated:

```markdown
# Implementation Progress: [Feature Name]

## Completed Tasks

### Task 1: Create database migration ✅
**Completed**: 2024-01-15
**Files Changed**:
- `migrations/001_create_auth_tables.sql` (created)
- `src/lib/db.ts` (modified)

**Notes**:
- Using UUID for user id
- Added index for email field

### Task 2: Setup JWT utilities ✅
**Completed**: 2024-01-15
**Files Changed**:
- `src/lib/jwt.ts` (created)
- `.env.example` (modified)

## Current Status
- Total tasks: 8
- Completed: 2
- Remaining: 6

## Next Task
Task 3: Implement login endpoint
```

## Tips

- Should implement 1-2 tasks at a time for easier review
- Always run tests after implementation
- Commit code frequently
