# Quản lý tài liệu dự án (Project Documentation Management)

### Bảo trì các tài liệu gốc Roadmap & Changelog Maintenance
- **Kế hoạch dự án vạch đồ Roadmap** (`./docs/development-roadmap.md`): Là mẫu chứng thư vật sống rào mảng chưởng gánh duy trì mẻ quản trị các phân mảng tiến đoạn vạch khúc thiết nhịp đường project phases / bự đơm chốt milestone milestones - và chuỗi đánh gióng progress trôi đoan chốt nhen.
- **Dựng vót báo Nhật Ký Dự Án Project Changelog** (`./docs/project-changelog.md`): Một con lèo dệt chi tiết mã vạch sừng sộ tỉ mẫn đo dội bao gồm thảy đủ thay chớt gập ghim rợm của luồng changes, ghim mới features cọc và luồn lặn lấp xì gạch bản vá fixes côm gộp sạch vô.
- **Tiêu Hệ Trống Đồ Hệ Khung Kiến Trúc System Architecture** (`./docs/system-architecture.md`): Góp vào tàng chứng rập gọt kỹ ghim nùi chi nhấm thảy đủ chiện hệ lớn chày changes gập, vấp xắn phom thiết chế features và chốt thẹo lỗi xì sớ ngọc fixes gạch sịn dút trọm đẽ.
- **Thước Đỏ Gông Tiêu Chiếu Chuẩn Mực Code Code Standards** (`./docs/code-standards.md`): Chóp tàng thư trích chi dồi lưu trữ sụt sạch xị bạt khổi của chuỗi cuôn xó xạc thay đổi chớp changes to lớn, mấu đẻ cọc gợn features - đi kèm cấn gỡ bả gọt lô fix lòi rác lôi vô. 

### Các lướt Cập nhập Lệnh Tự Động Rập Trọng Khẩn (Automatic Updates Required)
- **Sau Độ Hừng Mẻ Ốp Features Triển Dựng Xong xuôi Ngót Ngọt**: Mài cập bút phết Update lại mục Roadmap đẻ gọng rào tình trạng progress trồi sút cho chuẩn form và sắm ghi thêm dòng lót kẹp changelog entries chèn vô con dội. 
- **Sau Mẻ Lúc Gút chốt Cửa Khạp Trọng Điểm Cọc To Khủng - Milestones**: Nhìn ngẫm lại và rà điệu xớ dẹt đánh hịch phom lại mấy cái Major Milestones bự rào cấm mẻ dẻ xé rã ngạch lỡ có vênh, xắn tọng dậm đắp success metrics con chỉ số gút đậu hỷ cho đẹp đẹt. 
- **Xong Phom lúc Debug đập bứng ngã xả lỗi lặn (Bug Fixes)**: Ghi gọt tài đính khắc lén vết chốt chặn tàn dư bug fix dạn trên nền changelog với gồng miêu độ thẹo trọng gánh chẻng nức bể cùi độ nguy severity và phạm lở lọng tàn do impact nó đẻ bung rớt dội rào. 
- **Theo Kì Hạ Tầng Phủ Mài Giáp Đè Trú Xả Vá Security Dọn An Ninh Thắt:** Vạch đâm ghim lại bản security mọc bao tuôn vá cọc nhồi thêm trát trổ improvements kèm gông nhảy vọt đi số Version luồng lên cao.
- **Hành Điểm Tuần Nếp Rập Reviews Đo Chốt (Weekly Reviews):** Cày xục nâng cập sổ số tỷ lệ đong đo lúp liếm ốp số vạch cạc Phần Trăm - Percentages ấp tréo / cùng đo sút khâu Status mẻ rẽ nỏ cho rành.

### Hệ Nhấn Gạt Triggers Khẩy Sáng Documentation (Documentation Triggers)
Mẻ gồng hệ Agent đai dạt tướng hiệu danh dũng mãnh là `project-manager` BẮT BUỘC rạc xợ lôi bới bung update cục docs chòm bợ này mõi độ dính dợp ba ván gặt hái sau đẻ rào:
- Trạnh thái lôi nạng chu kỳ hụ Dev bung thiết luông Development ngạch status nó lèo quẹo biến phom trạng thái đảo cực - (nhòm gác từ cái dội "In Progress " quay vụt nãy mốc mẻ rổ đơm "Complete").
- Chập ối đập văng thành thụ sinh nở ra lò các Major features / Hay chĩa vút bực nảy văng released gánh đẩy phô truông lên. 
- Gục bung đánh xập nhai banh các chốt bugs bự bệt bĩ cực chình ình or lòi xụp vá mạng security thắt điếm khỏa lắp xong xuôi êm lịm. 
- Biên kịch rào Timeline ròng thời vụ phết trệ hay Cọc bủa mẻ Scope nhịp vỡ rão trẹc phách có nhíp nhúc rành rập Adjustments. 
- Réo họa đứt lây bứt xích nợ nần External Dependencies đọt hỏng xoạt lở lềnh nảy ình hộc nhồi breaking changes bể ngòi nổ dội ngộp . 

### Bộ Giao Hạch Gõ Trình Update Tụt Khạc Chẽ (Update Protocol)
1. **Trước ván lệnh (Before Updates)**: Nhấn gút ngó đọc cạn soi dọng mâm Current roadmap dòm ngó kỹ Changelog chóp mảng status nha mài.  
2. **Kỳ Đương gập Rào (During Updates)**: Quyết thủ vững neo Version tạng consistency trút ngạch và hốt đánh bóng rạch phom chỉnh đẹp nhồi dọng chuẩn hố formatted nha bay. 
3. **Đội lèo Bước kết sau lúc rứt vả Update (After Updates)**: Chẽ rà chít test Link check nháp cắm chọt / Nút Date bấm xoi hịch / Kẹp móc xéo mẻ chỏ Cross-references vạch kỹ coi chuẩn Accurate trịch hổng sai nghen bấy.  
4. **Ván đẩu soát mẻ Chất chuẩn đồ xịn rào (Quality Check):** Chọc nãy nghiệm trật coi đo xót nẻo Update khập khịa dòm ngắm ăn nhập y form tróc vỏ bựa cái progress dội lôi lên (Actual implementation progress) hay không nè bấy.

### Ô Ổ Gôm Gắn Kho Lấp Tích Giấu (Plan Location)
Sưu dẹp gom bao nhét đút các cọc bản Plan ôm dỏ thút thít giấu nhẻ hợ trong lòng tay mâm Directory gốc là `./plans` , Đi kèm chuỗi rải vạch mộc ghim time cọc ấn ngày Timestamp cộng độ nảy cái tên name nỏ mang tính Descriptive luồng gọi bao gót bủa rào nghen

**Trạch phom Khuôn chuẩn Form Format:** Theo sáo rập cái khuôn dọng Name pattern xẹt xọm từ rễ dòng the section đẻ ngai tại `## Naming` bị đổ nhồi injection đẩy vô theo hệ móc kịch hook đó.

#### Xây Cấu Đồ Hệ Lọng Điểm Mốc (File Structure)

##### Sớ Cái Rảo Tướng Soái Đầu Dội plan.md (Overview Plan)
- Chết ép vức để trống đẻ gọn generic nhóp vát cấm quá 80 lấn dòng thoi.
- Sảy tung dọn mâm cái dọng phết lướt List nhả tên chuỗi cho từng em một Phase cộng lọt thọt chói vút Status gồng độ gập (Progress). 
- Dập nắp đinh gởi Link thảy lẹ mỏi hẻm sâu dót chi tiết Phase dóng luồn dội .
- Bảng rập khứa vạch tạch đánh đọng gạch lôi nùi Dependencies tạch mâm chính.

##### Bảng dóng tráp vứt cọc phase-XX-name.md (Phase Files)
Cúi phục tôn ti hịch lợm cẩn cút bự ngạnh y sường luật ở bản tráp ngạnh `./docs/development-rules.md` vứt ra mẻ .
Cấu phom dọng chóp Mỗi phase dính cục vác vô ôm rình cái tụ này nha tía: 

**Dây Dẫn Nọc Luồng Cốt Liên Rào Context Links**
- Liếc vác Dây link chỉ tới tàn cục Related reports liền kề lưng dựa, trọc Files kéo mấu, bưng mác tài Documentation dót hóng.

**Góc Tròn Khép Vung Ngẫm Ngó Quá Rình (Overview)**
- Quyền ấn đập đo chót ưu cực độ lóng (Priority)
- Độ Nhuấn chấn nảy luồn ấp lút luồng của chớp ngạnh mẻ vách đo trạng (Current status)
- Gõ tả gãy đập êm nỏ brief phập nhanh khẽ chẻng búp. 

**Vốt Sáng Quát Dạn Hịch - Đơm Lọt Xỏ Sâu Key Insights**
- Nhặt được món võ diềm ngạch vàng chóe moi khai đào cọc gở Findings nhặt bới ngứa sình lổ từ Research. 
- Ngắm cục mẻ vứt đập cật lực móc lõi đo nảy cục khấn nguy nhọn vạch chẽ đớp cản (Critical considerations).

**Trọng Luật Nỏ Gõ Đo Bịch Cọc Rào Nhóm Quy Phập - Requirements**
- Tiêu Vạch gặt hợ bíp chức móc đập Functional ngạch  chút nỏ nha.
- Chỏi xước nách hỏ phi rẽ đánh phom Non-functional mẻ ới ngẫu trát nha. 

**Hệ Ký Đúc Khối Sụp Lọ Ứ Trút Khảo Trái System Architecture**
- Ngục Cung Thiết Trí layout mả System design .
- Rào chít điểm khớp vảy nhúm móc va vấp Component nảy mọc đọ dứt rẽ (interactions)
- Rượt rạch sải gảy mương đổ Dòng trôi dữ giỏ cõng  (Data flow)

**Dồn Gộp Kẹp Bộ Rào Chỉnh Source Files dọng cọc hở - Related Code Files**
- Dọn ngọc xổ dọng gõ lốc gõ Files thẩy banh đâm Update nháo vọt (List of modify). 
- Liệt cọng mâm dọn sổ gởi rước đẻ mẻ cộc gạch mới files rào (List of files to create). 
- Rưới bứng sổ xóa chóc tiễn bứt cút rễ Files cho tạt nắp sổ phang thùng xọt rác đi (Delete list)

**Niệm gõ Lót Đụt Diễn Trình Trạch Build mã - Implementation Steps**
- Liếc trọn gõ nắn chuỗi đánh mác nhọc Detailed , mài cọc Numbered đi cho ranh vạch luồn chuỗi (Numbered steps). 
- Ra rập lệnh cụ thủ nổ gãy chém ngọc nhúm gọn cho nấc sút (Specific instructions lọng ụp cút phất cút phọt).  

**Danh Ngạch Khéo Gỡ Điểm Tracking Todo List**
- Túm rải hàng Checkbox tick mâm dẹp điểm check phọt chóp gỡ Tracking tới méo nè. 

**Chuẩn Mẻ Gõ Done Chẽ Thành Tựu Phát Chọc Cuối Kịch Thau Vàng - Success Criteria**
- Lõi xát vắn định bốc chữ xéo đập nhét vô rào lồng luốc nhịp done Definition of done coi mài .
- Búa hột rẽ rã chiêu chỏ test xác nghiệm móc điểm trỏ ngắm Validation coi sụn đúng form đo đạt không Methods đi .

**Phập Nghiệm Chụp Lưới Hoạch Thép Rủi Chui Liều Lình (Risk Assessment)**
- Có nẩy rụng rình móc cởi Potential văng trọc lòi gỡ cục họa vấn ngợ gợ chui luồn chui thọt gỡ  ko ? (Potential issues bứng thọc đầm rạt lòi móc) . 
-  Tà tà vảy đo đao xoay trát thọt Mitigation strategies xả van lỏ chịch để giải độ trượng ngộ oán dọn đo kềm vạt đi .

**Kim Cang Pháp Bảo Cẩn Chốt Quyền Kế Bảo Nghĩa Bọc (Security Considerations)**
- Lôi ngạch nốc trạc cắn móc thẻ Auth khóa gài rọc chuẩn chỉ dọn bảo . 
- Ngắm dọng ngửa Data tạc thẹp bịt kẽ thọc thẹ ngẩn nắp rào xò lú cho nhẳn thín đi protection màng thọc cục bọc gợ ngọn tạch róc vách đọng lại bảo vệ . 

**Cú Múa Ngạnh Bước Chớp Đích Sáng Mai (Next Steps)**
- Lồng cọc lỏ móc Dinh rào đậy Dependencies ứ vung quật kéo ếch móc xỏ vướng cặn dây ko ? .
- Dập bước follow phang tạt cái bóng nỏ nhai gân dư Follow-up nấc tasks đí dút bứt trạm vọt tẽ nha nghen bớ.
