# Broad Incident Method

Use this method when the issue spans multiple surfaces or evidence sources.

## Signals for Broad Mode

- multiple components or directories involved
- conflicting evidence from different places
- unclear blast radius
- timeline matters
- a local loop keeps reopening the problem

## Method

### 1. Frame the incident
Capture:
- current symptom set
- affected surfaces
- likely impact radius
- immediate risks

### 2. Enumerate evidence sources
List the places evidence may live.
Keep sources separate until correlation is justified.

### 3. Reconstruct the timeline
Order key changes, observations, and failures.
Ask: what changed before the first visible break?

### 4. Narrow plausible causes
Rank candidate causes by evidence strength.
Reject guesses that have no path to proof.

### 5. Decide response mode
Choose one:
- continue investigation
- contain first, then investigate
- split work across evidence streams
- produce interim report for decision-makers

## Rules

- Treat blast radius as a hypothesis until confirmed.
- Keep source evidence distinct before merging narratives.
- Escalate to `investigation-scaling.md` if coordination becomes the main problem.
