## Contingency Plans

### If Survey Response <60% (Day 5-6)
- **Action:** Personal follow-up DMs
- **Fallback:** Use interviews + Slack feedback only
- **Timeline Impact:** None (can still proceed to interviews)

### If Critical Bugs Found (Day 12)
- **Action:** Immediate fix → v0.1.1 release
- **Timeline Impact:** +1 day (shift Day 15 dev start to Day 16)

### If Dev Overruns (Day 15-17)
- **Action:** Cut P1 features (keep P0 only)
- **Reduced Scope:** CLI flags + verbose + dry-run only (4.5h vs 11h)
- **Timeline Impact:** None (still release Day 21)

### If Beta Has Critical Bugs (Day 19-20)
- **Action:** Fix immediately on Day 20
- **Timeline Impact:** +1 day (release Day 22 instead of Day 21)
