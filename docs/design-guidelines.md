# Design Guidelines

## System
- CSS Framework: Tailwind CSS (active in `cafekit-web`)
- UI Library: Shadcn UI (inferred from component structure)
- Icons: Lucide React (standard for Shadcn)

## Patterns
- Mobile-first responsive design.
- Dark mode support (typical for dev tools).

## Responsive
- Uses standard Tailwind breakpoints (sm, md, lg, xl, 2xl).

## Theme
- Follows system preference or user toggle (if implemented in web).
