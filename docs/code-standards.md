# Code Standards

## Stack
- Language: TypeScript
- Framework: Node.js (CLI), React/Next.js (Web - inferred from cafekit-web)
- Styling: Tailwind CSS

## Conventions
- Use strict TypeScript types.
- Follow standard ESLint/Prettier configurations.
- Modularize agents and skills in `.agent` directory.

## File Organization
- `.agent/`: Agent configuration, skills, and workflows.
- `cafekit-web/`: Web application implementation.
- `docs/`: Project documentation.
