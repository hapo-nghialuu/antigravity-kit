# Project Overview (PDR)

## Identity
- **Name:** cafekit
- **Type:** AI Coding Assistant Tool
- **Status:** Active

## Description
Spec-Driven Development workflow for AI coding assistants. It works with both Claude Code and Antigravity, adding slash commands that guide you through building complex features.

## Features
- **Spec-Driven Development**: A structured 6-phase workflow.
- **Slash Commands**: `/spec-init`, `/spec-requirements`, `/spec-design`, `/spec-tasks`, `/spec-impl`, `/spec-status`.
- **Platform Support**: Works with Claude Code (`.claude/`) and Antigravity (`.agent/`).
- **Templates**: Skills, Agents, and Workflows for enhanced coding assistance.
